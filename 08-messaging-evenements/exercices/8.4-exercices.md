Cinq exercices, du plus simple au plus ouvert. Traite-les **dans l'ordre** et
écris tes réponses dans `mes-reponses/` avant d'ouvrir les corrections.

Les exercices s'appuient sur les paquets de la
[leçon 8.4](../cours/8.4-la-coherence-eventuelle.md) (`internal/pg`,
`ledger`, `projection`), recopiés tels quels dans le module des
exercices. Ils utilisent le PostgreSQL 17 du niveau 5 (`sd-pg`, port
55432). Tout le code ci-dessous compile et passe `go vet` ; les tontines
et l'incident sont **fictifs**.

## Exercice 3 — Refactoring : verser d'après la source

*Niveau 3. Réécrire une décision ; les tests sont fournis.*

```go
// Payout pays out the pot of round if its members contributions are all
// paid and not reversed, once. The decision reads the source, and no
// reversal can slip in between the count and the payout.
//
// Today it counts in the view, and inserts the payout.
func Payout(ctx context.Context, pool *pgxpool.Pool, round string, members int) error {
    var n int
    if err := pool.QueryRow(ctx, `SELECT count(*) FROM round_view WHERE round = $1 AND NOT reversed`, round).Scan(&n); err != nil {
        return err
    }
    if n < members {
        return ErrIncomplete
    }
    _, err := pool.Exec(ctx, `INSERT INTO payouts (round, pot) VALUES ($1, $2)`, round, int64(n)*10000)
    return err
}
```

## Exercice 5 — Incident : la vue figée du 11 décembre

*Niveau 7. Un incident à mesurer, puis à rejouer comme il aurait dû
être fait.*

Le vendredi 11 décembre 2026 à 10 h 12, une analyste ouvre une
transaction dans un outil SQL pour regarder les cotisations, puis part
déjeuner. Elle la referme à 12 h 42. Pendant ce temps, les membres qui
paient ne voient pas leur paiement apparaître, et beaucoup paient une
seconde fois.

```go
// Day plays the day on a fresh schema; the analyst's session runs
// analystSetup before opening its transaction. It returns the pool, for
// the audit, and the drop of the schema.
func Day(ctx context.Context, analystSetup string) (*pgxpool.Pool, func(), error) {
    pool, drop, err := pg.Fresh(ctx, ledger.Schema+projection.Schema)
    if err != nil {
        return nil, nil, err
    }
    l := &ledger.Ledger{Pool: pool}
    pctx, stop := context.WithCancel(ctx)
    p := &projection.Projector{Pool: pool, Every: Minute, Batch: 100}
    done := make(chan error, 1)
    go func() { done <- p.Run(pctx) }()

    start := time.Now()
    at := func(minute int) { time.Sleep(time.Until(start.Add(time.Duration(minute) * Minute))) }
    var wg sync.WaitGroup
    wg.Go(func() { // the analyst, from 10:12 to 12:42
        at(132)
        conn, err := pool.Acquire(ctx)
        if err != nil {
            panic(err)
        }
        defer conn.Release()
        if analystSetup != "" {
            if _, err := conn.Exec(ctx, analystSetup); err != nil {
                panic(err)
            }
        }
        tx, err := conn.Begin(ctx)
        if err != nil {
            panic(err)
        }
        if _, err := tx.Exec(ctx, `SELECT count(*) FROM contributions; SELECT pg_current_xact_id()`); err != nil {
            panic(err)
        }
        at(282)
        _ = tx.Rollback(ctx) // fails if the server ended the session
    })
    for i := range 200 {
        member := fmt.Sprintf("m%03d", i)
        wg.Go(func() {
            at(i * 2)
            for attempt := range 2 {
                c := ledger.Contribution{ID: fmt.Sprintf("c%03d-%d", i, attempt), Member: member, Round: "r1", Amount: 10000}
                pos, err := l.Record(ctx, c)
                if err != nil {
                    panic(err)
                }
                if projection.WaitFor(ctx, pool, pos, Minute, 10*Minute) == nil {
                    return // the payment shows
                }
            }
        })
    }
    wg.Wait()
    stop()
    if err := <-done; err != nil {
        drop()
        return nil, nil, err
    }
    return pool, drop, nil
}
```
