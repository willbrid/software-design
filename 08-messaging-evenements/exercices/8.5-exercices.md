## Exercice 1 — Compréhension : le point de non-retour

*Niveau 1. Aucune ligne de code à écrire.*

### 1.a — Trois sagas

Pour chacune, ordonne les étapes, nomme le point de non-retour, et donne
la compensation de chaque étape qui le précède.

1. **L'adhésion** : vérifier l'identité chez le prestataire, réserver une
   place dans la tontine, prélever les frais d'adhésion par Mobile Money,
   envoyer le SMS de bienvenue.
2. **Le versement d'une cagnotte avec frais** : fermer le tour, envoyer la
   cagnotte, prélever les frais de l'association sur la cagnotte, inscrire
   le versement dans les comptes.
3. **Le remboursement anticipé d'un prêt** : recevoir l'argent du membre,
   marquer le prêt remboursé, libérer la garantie.

### 1.b — Trois pourquoi

1. Pourquoi trois appels versent-ils 40 prêts deux fois, et la saga
   aucun ?
2. Pourquoi la saga qui prend le délai pour un échec laisse-t-elle 29
   versements sans prêt, alors qu'elle compense chaque échec ?
3. Pourquoi les deux mutations qui retirent un enregistrement d'étape
   survivent-elles ?

### 1.c — Orchestrer ou chorégraphier ?

Le contrôle d'identité, la réservation et les frais d'adhésion pourraient
réagir chacun aux événements du précédent. Qu'est-ce qui deviendrait
difficile ?

## Exercice 3 — Refactoring : verser une cagnotte

*Niveau 3. Réordonner une saga ; les tests sont fournis.*

```go
// Payout pays out the pot of round. Everything that may say no comes
// before the money goes out; after it, the payout only goes forward. A
// timeout is a question to the operator. The key of the payout is the
// round.
//
// Today it sends first, and takes any error of the operator for a
// failure.
func Payout(ctx context.Context, t Tontines, o Operator, b Books, round string, pot int64) error {
    if err := o.Send(ctx, "payout-"+round, pot); err != nil {
        return err
    }
    if err := t.Close(ctx, round); err != nil {
        return err
    }
    return b.Record(ctx, round, pot)
}
```

## Exercice 5 — Incident : le mardi des prêts de fin d'année

*Niveau 7. Un incident à mesurer, puis à rejouer comme il aurait dû
être fait.*

Le mardi 15 décembre 2026, un nouvel orchestrateur des prêts est
déployé le matin. 2 000 prêts de 75 000 FCFA sont demandés pour les
fêtes. En janvier, le rapprochement avec l'opérateur montre de l'argent
sorti pour des prêts que personne ne doit.

```go
// Tuesday runs the day with an orchestrator that does, or does not, ask
// the operator after a timeout, and returns the loans and the parts.
func Tuesday(checkTimeouts bool) ([]parts.Loan, parts.Parts) {
    ctx := context.Background()
    p := parts.New()
    o := &saga.Orchestrator{Parts: p, Store: &saga.Store{}, Crash: parts.Crash, CheckTimeouts: checkTimeouts, MaxSends: 3}
    loans := make([]parts.Loan, 2000)
    for i := range loans {
        loans[i] = parts.Loan{ID: fmt.Sprintf("dec15-%04d", i), Member: fmt.Sprintf("m%04d", i), Amount: 75000}
        _ = o.Run(ctx, loans[i])
    }
    o.Resume(ctx)
    return loans, p
}
```
