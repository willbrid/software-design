# Correction 8.6 — Exercice 5 : le rapport de l'année 2026

> Rappel de l'énoncé : un rapport annuel relu avec le lecteur du format
> courant ; mesurer, reconstruire avec le traducteur, rédiger.

L'audit et le rejeu sont dans `ex5` du module de correction, verts sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Les 300 membres sont sous-estimés**, de 53 210 000 FCFA en tout ;
  **281 auraient été exclus à tort**.
- **Avec le traducteur**, le rapport est juste : seuls les 15 membres
  réellement sous le seuil restent.
- **La cause** : un lecteur de v2 a lu les v1 avec un montant de 0 ;
  **la cause de la cause** : le rapport a été construit sans le
  traducteur, et sans contrôle contre un total connu.

## 1. L'audit

```go
func Compare(report, truth Report) Audit {
    a := Audit{Members: len(truth)}
    for member, want := range truth {
        got := report[member]
        if got < want {
            a.Understated++
            a.MissingFCFA += want - got
        }
        if got < Threshold && want >= Threshold {
            a.WronglyExcluded = append(a.WronglyExcluded, member)
        }
    }
    slices.Sort(a.WronglyExcluded)
    return a
}
```

## 2. Les chiffres, et le rejeu

`cmd/year` reconstruit le rapport des deux façons :

```text
7934 contributions of 300 members in 2026, 79340000 FCFA; 15 members truly under 150,000 FCFA

report read with          understated   missing FCFA  wrongly excluded
v2, tolerant                      300       53210000               281
upcast to v2                        0              0                 0
```

- **Avec le lecteur v2** : toutes les cotisations de janvier à août
  (v1 et v1.1) comptent 0. Les 300 membres sont sous-estimés, de
  53 210 000 FCFA sur 79 340 000. **281 membres** passent sous les
  150 000 FCFA alors qu'ils ont cotisé plus.
- **Avec le traducteur** : le rapport est juste, et les **15 membres**
  réellement sous le seuil sont les seuls concernés.

La liste « presque toute l'association » aurait dû alerter à elle seule :
un rapport qui contredit tout ce qu'on sait de l'année est faux avant
d'être surprenant.

## 3. La cause

**En une phrase** : le rapport a relu un journal d'un an avec un lecteur
qui ne connaissait que la version de septembre, et qui lisait, sans
erreur, un montant de 0 dans toutes les cotisations écrites avant.

**La cause de la cause** : la nouvelle équipe ne savait pas que le
journal contenait trois formats ; le traducteur existait (les autres
vues l'utilisaient) mais rien n'obligeait à passer par lui ; et le rapport
n'était comparé à aucun total connu (le total des cotisations de la
comptabilité).

## 4. Le compte rendu

1. **Quoi** : le rapport annuel 2026 sous-estimait les cotisations des
   300 membres de 53 210 000 FCFA au total ; la liste d'exclusion
   préparée pour l'assemblée du 9 janvier 2027 comptait 281 membres à
   tort.
2. **Cause** : le rapport lisait le journal avec le lecteur du format v2
   (septembre 2026), qui lit un montant de 0 dans les événements v1,
   écrits de janvier à août.
3. **Détection** : par la trésorière, devant une liste qui comptait
   presque toute l'association, avant le vote. Aucune exclusion n'a été
   prononcée.
4. **Correction** : le rapport est reconstruit avec le traducteur ; seuls
   les 15 membres réellement sous le seuil figurent sur la liste.
5. **Prévention** : les lecteurs du journal n'ont accès qu'à des
   événements déjà traduits (le paquet du contrat n'expose plus les
   lecteurs de chaque version) ; tout rapport est rapproché d'un total
   connu avant d'être utilisé ; les formats du journal et leurs dates sont
   documentés dans le registre des événements.

## Ce qu'il faut retenir

- Un lecteur d'une seule version, sur un journal de plusieurs, lit faux
  sans erreur.
- Rendre le traducteur obligatoire, pas seulement disponible.
- Un rapport se rapproche d'un total connu avant d'être cru.
