# Correction 8.4 — Exercice 2 : lire ce qu'on vient d'écrire

> Rappel de l'énoncé : répondre depuis la vue une fois qu'elle a atteint
> la dernière écriture du membre, ou depuis la source si elle tarde.

La solution est dans `ex2` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Sans écriture dans la session**, la vue répond tout de suite.
- **Avec une écriture**, on attend la position, au plus `patience`.
- **Si la vue tarde**, la source répond, pour ce membre seulement.

## 1. La solution

```go
func Paid(ctx context.Context, pool *pgxpool.Pool, round, member string, written int64, patience time.Duration) (bool, Where, error) {
    if written > 0 {
        err := projection.WaitFor(ctx, pool, written, 10*time.Millisecond, patience)
        if errors.Is(err, projection.ErrNotYet) {
            var ok bool
            err := pool.QueryRow(ctx, `SELECT exists (SELECT 1 FROM contributions WHERE round = $1 AND member = $2 AND NOT reversed)`,
                round, member).Scan(&ok)
            return ok, FromSource, err
        }
        if err != nil {
            return false, "", err
        }
    }
    ok, err := projection.Paid(ctx, pool, round, member)
    return ok, FromView, err
}
```

La source ne répond que pour la question posée (un membre, un tour) : une
requête sur la clé primaire et un index, aussi rapide que la vue. Ce
n'est pas l'écran entier qui bascule sur la source, seulement la ligne
que le membre vient d'écrire.

## 2. Pourquoi ne pas lire la source tout le temps

Pour ce membre et cette question, on pourrait. Mais l'écran entier (le
tour, ses 25 membres, les retards, les montants) est ce que la vue sait
servir et la source moins bien : c'est la raison d'être de la vue. La
source n'est appelée qu'en **secours**, quand la vue est en retard sur ce
que le membre sait déjà. En temps normal, `WaitFor` rend la main en
quelques dizaines de millisecondes, et la source n'est jamais lue.

Le jour où la vue s'arrête (exercice 5), tout bascule sur la source : la
charge de la source monte, mais les membres voient juste. Ce basculement
se surveille : le nombre de réponses `FromSource` est une métrique, et
une hausse dit que la vue est en retard.

## Ce qu'il faut retenir

- L'écriture rend une position ; la lecture l'attend.
- La source est le secours, pour la seule ligne écrite.
- Compter les réponses de secours mesure le retard de la vue.
