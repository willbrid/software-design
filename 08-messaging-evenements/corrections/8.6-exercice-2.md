# Correction 8.6 — Exercice 2 : une troisième version

> Rappel de l'énoncé : écrire le traducteur vers v3, où le montant
> devient un objet avec sa devise.

La solution est dans `ex2` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **v3 se lit directement**, et se refuse sans devise.
- **v1 et v2 passent par le traducteur existant**, puis reçoivent la
  devise XOF.
- **Une version inconnue** reste une erreur, transmise par le traducteur
  de v2.

## 1. La solution

```go
func Upcast(e store.Event) (V3, error) {
    if e.Version == 3 {
        var v V3
        if err := json.Unmarshal(e.Body, &v); err != nil {
            return V3{}, fmt.Errorf("event %d: %w", e.Seq, err)
        }
        if v.Amount.Currency == "" {
            return V3{}, fmt.Errorf("event %d: v3 without a currency", e.Seq)
        }
        return v, nil
    }
    v2, err := contract.Upcast(e) // versions 1 and 2, and the unknown ones
    if err != nil {
        return V3{}, err
    }
    return V3{Contribution: v2.Contribution, Round: v2.Round, Amount: Money{v2.AmountFCFA, "XOF"}, Channel: v2.Channel}, nil
}
```

Le test `TestUpcastRefusesWhatItCannotRead` envoie un v3 dont `amount`
est un nombre : `json.Unmarshal` refuse de le mettre dans `Money`. Une
v3 dont l'objet n'a pas de devise passerait le décodage, d'où la
vérification explicite : un montant sans devise, en v3, est un défaut de
l'écrivain, pas un montant en FCFA.

## 2. La chaîne de traducteurs

**L'avantage** : chaque traducteur ne connaît que le pas d'une version à
la suivante. Ajouter v3 n'a demandé qu'un pas (v2 → v3) ; les anciens
traducteurs, déjà testés, ne bougent pas.

**Le risque** : la chaîne s'allonge à chaque version, et un événement de
v1 traverse tous les pas à chaque lecture. Une erreur dans un pas
ancien touche tous les événements anciens, et se voit tard. Quand la
chaîne devient longue, on peut écrire un raccourci (v1 → v3 direct),
testé contre la chaîne, ou faire une **copie transformée** du journal
dans le nouveau format (Greg Young l'appelle *Copy-Transform*), en
gardant l'ancien intact.

## Ce qu'il faut retenir

- Un pas de traduction par version.
- Une valeur par défaut (la devise) se décide au moment de traduire, pas
  au moment de lire.
- Une chaîne trop longue se raccourcit, testée contre elle.
