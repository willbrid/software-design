# Correction 8.2 — Exercice 3 : fermer un tour sans perdre l'annonce

> Rappel de l'énoncé : réécrire la fermeture d'un tour pour que
> l'événement `RoundClosed` existe si, et seulement si, le tour a été
> fermé par cet appel.

La solution est dans `ex3` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Une transaction** contient le `UPDATE` et l'insertion dans l'outbox.
- **`pgx.ErrNoRows`, et seulement lui,** veut dire « déjà fermé ».
- **Le relais publie**, plus la fermeture.

## 1. La solution

```go
// Close marks the round closed and announces RoundClosed, with the round
// as key; the event exists if, and only if, the round was closed by this
// call. The relay of the outbox publishes it.
func (c *Closer) Close(ctx context.Context, round string) error {
    tx, err := c.Pool.Begin(ctx)
    if err != nil {
        return err
    }
    defer tx.Rollback(ctx)
    var beneficiary string
    var pot int64
    err = tx.QueryRow(ctx,
        `UPDATE rounds SET closed = true WHERE id = $1 AND NOT closed RETURNING beneficiary, pot`, round).
        Scan(&beneficiary, &pot)
    if errors.Is(err, pgx.ErrNoRows) {
        return ErrAlreadyClosed
    }
    if err != nil {
        return err
    }
    if c.Crash != nil && c.Crash() {
        return ErrCrash
    }
    body, _ := json.Marshal(map[string]any{"round": round, "beneficiary": beneficiary, "pot": pot})
    if err := outbox.Append(ctx, tx, round, "RoundClosed", body); err != nil {
        return err
    }
    return tx.Commit(ctx)
}
```

La condition `AND NOT closed` du `UPDATE` fait le travail de la leçon
5.3 : deux fermetures simultanées du même tour, une seule trouve la ligne
encore ouverte, une seule écrit l'événement. La seconde lit `ErrNoRows`.

## 2. Ce que cachait `ErrAlreadyClosed`

Le code d'origine renvoyait `ErrAlreadyClosed` pour **toute** erreur :
une base injoignable, un délai dépassé, une connexion coupée. Le
programme appelant lisait « déjà fermé », ne réessayait pas, et le tour
restait ouvert, sans versement. C'est la leçon 1.5 : une erreur traduite
trop large ment. La correction ne traduit que `pgx.ErrNoRows`, et laisse
remonter les autres.

## 3. Ce qui n'a pas changé

La fermeture renvoie maintenant **avant** que l'événement soit publié.
Le SMS, les statistiques et la trésorière l'apprennent au prochain
passage du relais. Si le relais lit toutes les secondes, c'est une
seconde de plus ; s'il est arrêté, c'est l'alerte de l'exercice 2 qui
le dit.

## Ce qu'il faut retenir

- L'événement et le changement, dans la même transaction.
- Ne traduire que l'erreur qu'on comprend.
- La condition du `UPDATE` décide qui a fermé : un seul événement.
