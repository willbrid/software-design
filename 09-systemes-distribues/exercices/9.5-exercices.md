## Exercice 1 — Compréhension : quelle défense contre quoi ?

*Niveau 1. Aucune ligne de code à écrire.*

### 1.a — Six attaques

ligne de défense limite les dégâts quand la première manque.

1. Un membre remplace `m007` par `m008` dans l'adresse de son
   portefeuille.
2. Quelqu'un appelle l'adresse de confirmation avec un corps inventé.

   l'opérateur et les renvoie.
4. La trésorière tape `x' UNION SELECT ...` dans la recherche.
5. Un attaquant qui a obtenu le secret du webhook envoie de fausses
   confirmations.
6. Un membre renvoie une confirmation vraie, capturée la veille sur son
   propre téléphone.

1. Pourquoi un portefeuille interdit répond-il `404` et pas `403` ?
2. Pourquoi l'horodatage doit-il être signé avec le corps ?
3. Pourquoi le rôle limité ne suffit-il pas, seul, contre l'injection ?

### 1.c — Le sens des mesures

Dans `cmd/webhook`, la copie « renvoyée tout de suite » passe une fois sur
50 avec la meilleure vérification. Est-ce une faille ?

## Exercice 5 — Incident : les confirmations rejouées du 14 décembre

*Niveau 7. Un incident à mesurer, puis à rejouer comme il aurait dû
être fait.*

Le lundi 14 décembre 2026, l'adresse de confirmation vérifie la
signature de l'opérateur, et rien d'autre. Le soir, le tableau des tours
annonce plus d'argent reçu que l'opérateur n'en a versé.

```go
// Monday plays the day against a receiver of the given level, and
// returns the credits the board made, and what the operator really
// confirmed (contribution -> amount).
func Monday(level webhook.Level) (credits []Credit, truth map[string]int64) {
    secret := []byte("shared with the operator only")
    r := &webhook.Receiver{Secret: secret, Level: level, Window: 5 * time.Minute}
    start := time.Date(2026, 12, 14, 8, 0, 0, 0, time.UTC)
    truth = map[string]int64{}
    type sent struct {
        ts, sig string
        body    []byte
        at      time.Time
    }
    var captured []sent
    deliver := func(s sent, at time.Time) {
        if r.Check(s.ts, s.sig, s.body, at) != nil {
            return
        }
        var c webhook.Confirmation
        json.Unmarshal(s.body, &c)
        credits = append(credits, Credit{c.Contribution, c.Amount})
    }
    for i := range 2000 {
        at := start.Add(time.Duration(i) * 15 * time.Second)
        c := webhook.Confirmation{ID: fmt.Sprintf("op-%04d", i), Contribution: fmt.Sprintf("c%04d", i), Amount: int64(5000 + 500*(i%10))}
        truth[c.Contribution] = c.Amount
        body, _ := json.Marshal(c)
        ts := strconv.FormatInt(at.Unix(), 10)
        s := sent{ts, webhook.Sign(secret, ts, body), body, at}
        deliver(s, at)
        if i%25 == 3 { // the operator did not get our answer, and sends again
            deliver(s, at.Add(40*time.Second))
        }
        if i%66 == 10 && len(captured) < 30 {
            captured = append(captured, s)
        }
    }
    for k := range 20 {
        for _, s := range captured {
            deliver(s, s.at.Add(time.Duration(k+1)*17*time.Minute))
        }
    }
    return credits, truth
}
```
