## Exercice 1 — Compréhension : lire les signaux

*Niveau 1. Aucune ligne de code à écrire.*

### 1.a — Le budget

L'API des paiements a un objectif de 99,9 % de réussite sur 30 jours, et
reçoit 300 requêtes par minute.

1. Combien d'erreurs le budget autorise-t-il sur le mois ?
2. Une panne fait échouer 2 % des requêtes. Quel est le taux de
   combustion ? En combien de temps le budget est-il épuisé ?
3. Avec l'objectif de 99,5 % de la leçon, que deviennent ces deux
   réponses ?

### 1.b — Ce qu'on écrit

Pour chaque champ, dis s'il va dans un journal, une métrique, une trace,
ou nulle part.

1. L'identifiant de la requête.
2. L'identifiant du membre.
3. Le numéro de sa pièce d'identité.
4. La route (`POST /contributions`).
5. Le code PIN Mobile Money saisi par le membre.
6. La durée de l'appel à l'opérateur.
7. Le montant de la cotisation.

### 1.c — Trois pourquoi

1. Pourquoi la moyenne des 99e centiles de trois instances est-elle
   fausse, alors que la fusion de leurs histogrammes est juste ?
2. Pourquoi, sans `traceparent`, 50 requêtes donnent-elles 200 traces ?
3. Pourquoi les alertes sur le budget ne sonnent-elles pour aucune des 60
   pointes ?

## Exercice 3 — Refactoring : le reçu qui se souvient de sa requête

*Niveau 3. Réécrire un gestionnaire ; les tests sont fournis.*

```go
// Service pays. Out is where the logs go; every line written for a
// payment, the background receipt included, must be JSON with the
// payment's request_id (the X-Request-Id header), the member and the
// amount where they make sense.
//
// Today it writes free text, without the request id, and the receipt
// runs with a context that dies with the request.
type Service struct {
    Out     io.Writer
    Receipt func(ctx context.Context, member string) error
    wg      sync.WaitGroup
}
```

```go
// ServeHTTP records a payment.
func (s *Service) ServeHTTP(w http.ResponseWriter, r *http.Request) {
    log := slog.New(slog.NewTextHandler(s.Out, nil))
    _ = logs.WithRequest
    member, amount := r.URL.Query().Get("member"), r.URL.Query().Get("amount")
    log.Info("payment received " + member + " " + amount)
    ctx := r.Context()
    s.wg.Go(func() {
        if err := s.Receipt(ctx, member); err != nil {
            log.Error("receipt failed: " + err.Error())
            return
        }
        log.Info("receipt sent")
    })
    w.Write([]byte("paid"))
}
```
