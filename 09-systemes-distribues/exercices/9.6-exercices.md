## Exercice 1 — Compréhension : quelle horloge, quel ordre ?

*Niveau 1. Aucune ligne de code à écrire.*

### 1.a — Six usages du temps

Pour chacun, dis quelle horloge utiliser (monotone de la machine, murale
de la machine, horloge de la base), ou s'il faut autre chose qu'une
horloge.

1. Mesurer la durée d'un appel à l'opérateur.
2. Afficher au membre la date de sa cotisation.
3. Décider qu'une session ouverte par une autre instance a expiré.
4. Choisir, entre deux modifications du profil d'un membre faites depuis
   deux instances, laquelle garder.
5. Ordonner les étapes d'une trace qui traverse quatre services.
6. Savoir si un bail est encore valide, depuis le travailleur qui le tient.

### 1.b — Trois pourquoi

1. Pourquoi un retard de 400 ms ne fait-il perdre aucune mise à jour, et
   un retard de 2 s presque la moitié ?
2. Pourquoi A continue-t-il d'envoyer après s'être réveillé, alors que le
   bail a expiré ?
3. Pourquoi vérifier le bail juste avant chaque envoi ne suffirait-il
   pas ?

### 1.c — Le bail et la clé

Le relevé d'un membre pourrait porter une clé d'idempotence (le membre et
le mois), que la passerelle refuserait de voir deux fois. Que protège-t-elle
que le jeton ne protège pas, et inversement ?

```go
// Valid reports whether the session token exists and has not expired,
// whatever the clock of the instance that asks.
//
// Today it compares the expiry with the instance's clock.
func Valid(ctx context.Context, pool *pgxpool.Pool, clock Clock, token string) (bool, error) {
    var expires time.Time
    err := pool.QueryRow(ctx, `SELECT expires_at FROM sessions WHERE token = $1`, token).Scan(&expires)
    if err != nil {
        return false, nil
    }
    return clock.Now().Before(expires), nil
}
```

## Exercice 5 — Incident : les relevés de la nuit du 31 décembre

*Niveau 7. Un incident à mesurer, puis à rejouer comme il aurait dû
être fait.*

La nuit du 31 décembre 2026, le travailleur A envoie les relevés annuels
de 300 membres. Au membre 100, sa machine virtuelle est déplacée sur un
autre hôte et s'arrête 40 secondes ; le travailleur B prend le relais. Le
lendemain, des membres signalent avoir reçu deux relevés, dont un avec un
solde faux.

```go
// Night sends the statements and returns what left the gateway, in order.
func Night(fenced bool) ([]sender.Delivery, error) {
    ctx := context.Background()
    pool, drop, err := pg.Fresh(ctx, lease.Schema+job.Schema)
    if err != nil {
        return nil, err
    }
    defer drop()
    gw := &sender.Gateway{Fenced: fenced}
    a := &job.Worker{Pool: pool, Gateway: gw, Name: "A", TTL: 300 * time.Millisecond, RenewEvery: 20, Members: 300, PauseAt: 100, Pause: 600 * time.Millisecond}
    b := &job.Worker{Pool: pool, Gateway: gw, Name: "B", TTL: 300 * time.Millisecond, RenewEvery: 20, Members: 300}
    var wg sync.WaitGroup
    wg.Go(func() { a.Run(ctx) })
    time.Sleep(10 * time.Millisecond)
    wg.Go(func() { b.Standby(ctx, 50*time.Millisecond) })
    wg.Wait()
    return gw.Log(), nil
}
```
