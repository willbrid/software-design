## Exercice 1 — Compréhension : réessayer ou pas ?

*Niveau 1. Aucune ligne de code à écrire.*

### 1.a — Huit échecs

Pour chacun, dis s'il faut réessayer, et pourquoi.

1. `GET /balance` répond `503` avec `Retry-After: 5`.
2. `POST /payouts` sans clé d'idempotence n'a pas répondu en 300 ms.
3. `POST /payouts` avec une clé d'idempotence n'a pas répondu en 300 ms.
4. `GET /member/42` répond `404`.
5. `POST /contributions` répond `400` : montant négatif.
6. `GET /rates` : connexion refusée.
7. `POST /payouts` avec clé répond `500`.
8. `GET /score` répond `429` avec `Retry-After: 120`, et l'écran a 800 ms.

### 1.b — Trois couches

L'écran réessaie 3 fois le service des prêts, qui réessaie 3 fois
l'opérateur, qui réessaie 3 fois sa base. La base est en panne. Combien
d'appels reçoit-elle pour un clic du membre ? Et si chaque appel attend
2 s avant d'échouer, combien de temps attend le membre ?

### 1.c — Trois pourquoi

1. Pourquoi « trois essais tout de suite » n'a-t-il rien changé, ni en
   bien ni en mal ?
2. Pourquoi le hasard n'a-t-il pas suffi à protéger le service ?
3. Pourquoi le coupe-circuit fait-il échouer quelques requêtes de plus
   que le simple délai ?

## Exercice 3 — Refactoring : une seule couche réessaie

*Niveau 3. Réécrire une chaîne d'appels ; les tests sont fournis.*

```go
// Loans asks the operator.
type Loans struct {
    Operator Operator
    Retry    retry.Policy // the retries of the loans team
}
```

```go
// MaxLoan returns what member may borrow: three times their balance.
//
// Today it retries the operator with its own policy, and gives each call
// 2 s whatever its caller has left.
func (l *Loans) MaxLoan(ctx context.Context, member string) (int64, error) {
    var balance int64
    err := l.Retry.Do(ctx, func(context.Context) error {
        cctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
        defer cancel()
        var err error
        balance, err = l.Operator.Balance(cctx, member)
        return err
    })
    return 3 * balance, err
}
```

```go
// Show returns what to show. Only one layer may retry: the screen,
// which knows how long the member can wait. Every call below uses what is
// left of the screen's budget.
//
// Today the screen retries too.
func (s *Screen) Show(ctx context.Context, member string) (int64, error) {
    ctx, cancel := context.WithTimeout(ctx, s.Budget)
    defer cancel()
    var max int64
    err := s.Retry.Do(ctx, func(ctx context.Context) error {
        var err error
        max, err = s.Loans.MaxLoan(ctx, member)
        return err
    })
    return max, err
}
```

## Exercice 5 — Incident : la panne de l'opérateur du 2 décembre

*Niveau 7. Un incident à mesurer, puis à rejouer comme il aurait dû
être fait.*

Le mercredi 2 décembre 2026, l'opérateur tombe trois minutes. Il revient,
mais l'application met encore de longues minutes à servir ses membres
normalement. L'opérateur, lui, signale avoir reçu un trafic inhabituel à
son retour.

```go
// Day sends 200 requests per second for 10 s; the operator is down from
// 1 s to Up. It serves 300 per second at most; each call gives up after
// 300 ms.
func Day(p retry.Policy) []Outcome {
    d := &dep.Dep{Capacity: 6, Service: 20 * time.Millisecond}
    srv := httptest.NewServer(d)
    defer srv.Close()
    t := srv.Client().Transport.(*http.Transport)
    t.MaxIdleConnsPerHost = 500
    hc := &http.Client{Transport: t, Timeout: 300 * time.Millisecond}
    start := time.Now()
    go func() {
        time.Sleep(time.Second)
        d.Set(dep.Down)
        time.Sleep(Up - time.Second)
        d.Set(dep.Healthy)
    }()
    var (
        mu  sync.Mutex
        out []Outcome
        wg  sync.WaitGroup
    )
    for i := range 2000 {
        time.Sleep(time.Until(start.Add(time.Duration(i) * 5 * time.Millisecond)))
        wg.Go(func() {
            sent := time.Since(start)
            ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
            defer cancel()
            err := p.Do(ctx, func(ctx context.Context) error { return client.Call(ctx, hc, srv.URL) })
            mu.Lock()
            defer mu.Unlock()
            out = append(out, Outcome{SentAt: sent, OK: err == nil})
        })
    }
    wg.Wait()
    return out
}
```
