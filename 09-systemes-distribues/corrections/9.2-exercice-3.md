# Correction 9.2 — Exercice 3 : une seule couche réessaie

> Rappel de l'énoncé : garder les tentatives dans l'écran seulement, et
> faire respecter son budget par chaque appel en dessous.

La solution est dans `ex3` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Les prêts n'ont plus de politique de tentatives** : ils appellent une
  fois.
- **Leur délai part du contexte reçu** : `context.WithTimeout` sur un
  contexte qui a déjà un délai garde le plus court.
- **L'écran garde ses 3 tentatives**, dans ses 500 ms.

## 1. La solution

```go
// Loans asks the operator.
type Loans struct {
    Operator Operator
    // CallTimeout bounds one call to the operator, within what the
    // caller has left.
    CallTimeout time.Duration
}
```

```go
func (l *Loans) MaxLoan(ctx context.Context, member string) (int64, error) {
    if l.CallTimeout > 0 {
        var cancel context.CancelFunc
        ctx, cancel = context.WithTimeout(ctx, l.CallTimeout) // the shorter of the two
        defer cancel()
    }
    balance, err := l.Operator.Balance(ctx, member)
    return 3 * balance, err
}
```

```text
ok      example/corrections92/ex3       1.514s
```

Le défaut d'origine le plus grave n'était pas le nombre de tentatives,
mais `context.WithTimeout(context.Background(), 2*time.Second)` : le
contexte de l'appelant était **jeté**, et chaque appel à l'opérateur
avait 2 s, même quand l'écran n'avait plus que 50 ms. Le test qui
mesurait 2 s au lieu de 500 ms le montrait.

## 2. Pourquoi l'écran

C'est la seule couche qui sait **combien de temps le membre peut
attendre**, et **ce que vaut la réponse** (un écran de prêt peut afficher
« réessayez dans un instant »). La couche la plus proche de l'opérateur
connaît mieux ses erreurs ; elle peut **classer** l'erreur (passagère ou
permanente, exercice 2) et la remonter, mais pas décider d'y passer le
temps de quelqu'un d'autre.

Il y a une exception : une couche qui a besoin d'une tentative pour être
correcte (un relais d'outbox, une saga) réessaie elle-même, parce que
personne au-dessus n'attend.

## Ce qu'il faut retenir

- Une seule couche réessaie : celle qui connaît l'attente.
- On ne jette jamais le contexte reçu.
- Les couches du dessous classent l'erreur, elles ne réessaient pas.
