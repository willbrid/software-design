# Correction 9.6 — Exercice 5 : les relevés de la nuit du 31 décembre

> Rappel de l'énoncé : un travailleur endormi plus longtemps que son bail,
> une passerelle qui ne vérifie pas les jetons ; mesurer, rejouer,
> rédiger.

L'audit et le rejeu sont dans `ex5` du module de correction, verts sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **20 relevés envoyés par un détenteur périmé**, à chaque exécution ;
  le nombre de membres servis deux fois varie (9 dans le rejeu ci-dessous,
  jusqu'à 74 dans la leçon), selon le croisement des deux travailleurs.
- **Avec une passerelle qui vérifie les jetons**, aucun.
- **La cause** : un détenteur qui ne savait pas avoir perdu son bail ;
  **la cause de la cause** : rien, là où l'on écrivait, ne savait qui
  était le détenteur.

## 1. L'audit

```go
func Audit(log []sender.Delivery) Report {
    r := Report{Statements: len(log)}
    times := map[string]int{}
    var highest int64
    for _, d := range log {
        times[d.Member]++
        if d.Token < highest {
            r.Stale++
        }
        highest = max(highest, d.Token)
    }
    for _, n := range times {
        r.Members++
        if n > 1 {
            r.Twice++
        }
    }
    return r
}
```

Un relevé est « périmé » si son jeton est plus petit qu'un jeton déjà vu
par la passerelle : quelqu'un d'autre avait pris le bail avant lui.

## 2. Les chiffres, et le rejeu

`cmd/newyear` rejoue la nuit deux fois :

```text
300 yearly statements; worker A stops at member 100 for longer than its lease

gateway                   statements  members   twice sent by a stale holder
sends whatever it gets           309      300       9                     20
checks the token                 300      300       0                      0
```

- **La passerelle sans vérification** : A, réveillé, envoie **20 relevés**
  sous son ancien jeton avant de découvrir, à son renouvellement, que le
  bail est à B. Ces 20 relevés ont pu être calculés **avant** son sommeil,
  sur des soldes depuis corrigés : c'est le « solde faux » signalé. Le
  nombre de membres servis deux fois dépend de la façon dont A et B se
  croisent dans la table du travail : 9 ici, 11 à 74 dans d'autres
  exécutions.
- **La passerelle qui vérifie les jetons** : le premier relevé de A après
  son réveil est refusé (le jeton de B est plus grand), et A s'arrête.
  300 relevés, 300 membres, aucun périmé.

## 3. La cause

**En une phrase** : le travailleur A, arrêté plus longtemps que son bail,
a continué d'envoyer des relevés à son réveil, sans savoir que B les
envoyait déjà.

**La cause de la cause** : la conception supposait qu'un détenteur de bail
sait s'il le tient encore. Il ne le peut pas : entre deux vérifications,
il peut s'arrêter sans le savoir. La seule protection possible est chez
celui qui reçoit les envois, et la passerelle ne connaissait pas les
jetons.

## 4. Le compte rendu

1. **Quoi** : la nuit du 31 décembre 2026, des membres ont reçu leur
   relevé annuel deux fois ; 20 relevés ont été envoyés par un travailleur
   qui avait perdu le droit de le faire, certains avec un solde périmé.
2. **Cause** : la machine virtuelle du travailleur A a été déplacée et
   arrêtée 40 secondes ; son bail de 30 secondes a expiré, B l'a pris ; A,
   à son réveil, a continué jusqu'à son renouvellement suivant.
3. **Détection** : par les membres, le 1er janvier ; aucun contrôle ne
   comptait les relevés envoyés par membre.
4. **Correction** : un relevé rectificatif est envoyé aux membres dont le
   relevé périmé portait un solde faux ; la passerelle vérifie désormais
   les jetons, et refuse un relevé déjà envoyé pour le même membre et la
   même année.
5. **Prévention** : chaque écriture d'un travailleur unique porte un
   jeton de clôture (exercice 2) ; chaque envoi porte une clé
   d'idempotence ; un test qui endort un travailleur plus longtemps que son
   bail fait partie de la suite de chaque travail unique.

## Ce qu'il faut retenir

- Un détenteur ne peut pas savoir qu'il a perdu son bail.
- C'est le récepteur qui refuse le périmé.
- Clé contre les doublons, jeton contre les périmés.
