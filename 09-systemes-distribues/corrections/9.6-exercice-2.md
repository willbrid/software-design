# Correction 9.6 — Exercice 2 : une table clôturée

> Rappel de l'énoncé : écrire le prochain bénéficiaire d'un tour au nom
> d'un détenteur, en refusant un détenteur plus ancien que le dernier
> écrivain.

La solution est dans `ex2` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **La condition `fence <= $3`** est dans le `UPDATE` lui-même.
- **Une seule instruction** lit la clôture, écrit, et dit pourquoi elle
  n'a pas écrit.
- **Un tour absent** est une erreur distincte de la clôture.

## 1. La solution

```go
func SetBeneficiary(ctx context.Context, pool *pgxpool.Pool, round, beneficiary string, token int64) error {
    var fenced bool
    err := pool.QueryRow(ctx, `
        WITH r AS (SELECT fence FROM rounds WHERE id = $1),
             done AS (UPDATE rounds SET beneficiary = $2, fence = $3 WHERE id = $1 AND fence <= $3 RETURNING 1)
        SELECT NOT EXISTS (SELECT 1 FROM done) FROM r`, round, beneficiary, token).Scan(&fenced)
    if errors.Is(err, pgx.ErrNoRows) {
        return fmt.Errorf("round %s: %w", round, err)
    }
    if err != nil {
        return err
    }
    if fenced {
        return ErrFenced
    }
    return nil
}
```

```text
ok      example/corrections96/ex2       1.163s
```

`r` dit si le tour existe ; `done`, si l'écriture a eu lieu. Pas de ligne
dans `r` : le tour n'existe pas (`ErrNoRows`). Une ligne dans `r` mais
pas dans `done` : la clôture a refusé.

## 2. Pourquoi une seule instruction

Lire la clôture, puis écrire, laisse un instant entre les deux. Deux
détenteurs (le jeton 3 et le jeton 7) lisent tous deux une clôture de 2,
tous deux concluent qu'ils peuvent écrire, et le jeton 3 écrit **après**
le jeton 7 : la clôture n'a rien clôturé. C'est la mise à jour perdue de
la leçon 5.3, sur la clôture elle-même. Dans une seule instruction,
PostgreSQL verrouille la ligne pour l'`UPDATE` et réévalue la condition
sur la version la plus récente : le jeton 3, s'il arrive second, voit la
clôture à 7 et n'écrit pas.

## Ce qu'il faut retenir

- La clôture se vérifie dans l'écriture, pas avant.
- Une instruction qui dit pourquoi elle n'a pas écrit.
- Un refus de clôture n'est pas un objet absent.
