# Correction 11.4 — Exercice 3 : vérifier une restauration

> Rappel de l'énoncé : écrire `Fingerprint`, qui résume le contenu d'une
> table pour comparer l'original et la copie restaurée.

La solution est dans `ex3` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Le nombre de lignes, et une empreinte de leur texte** dans un ordre
  fixé par une colonne.
- **Le texte de la ligne entière** : chaque colonne compte, et `NULL`
  se distingue de la chaîne vide.
- **Les noms passent par `pgx.Identifier`**, jamais collés tels quels.

## 1. La solution

```go
func Fingerprint(ctx context.Context, q Querier, table, orderBy string) (rows int64, digest string, err error) {
    t, o := pgx.Identifier{table}.Sanitize(), pgx.Identifier{orderBy}.Sanitize()
    err = q.QueryRow(ctx, `SELECT count(*), coalesce(md5(string_agg(r::text, E'\n' ORDER BY r.`+o+`)), '')
        FROM `+t+` AS r`).Scan(&rows, &digest)
    return rows, digest, err
}
```

## 2. Pourquoi un ordre

Une table restaurée n'a pas forcément ses lignes dans le même ordre
physique que l'original : `pg_restore` en parallèle, un `VACUUM FULL`,
des mises à jour les déplacent. Sans `ORDER BY`, la base les rend dans
leur ordre physique, et deux tables identiques donneraient deux
empreintes différentes. Le test construit la seconde table dans l'ordre
inverse ; la mutation « sans ordre » est tuée par ce seul cas.

## 3. Ce que l'empreinte ne dit pas

Elle dit que les lignes sont les mêmes ; elle ne dit pas que les index,
les contraintes, les droits et les séquences sont revenus. Une
vérification complète compare aussi la liste des objets (les index
valides, les contraintes, les rôles), et lance quelques requêtes de
l'application sur la copie. Pour une très grosse table, on calcule
l'empreinte par tranche de clé (par mois), pour pouvoir dire **où** elle
diffère.

## Ce qu'il faut retenir

- Une restauration se vérifie par des comptes et des empreintes.
- Un ordre explicite, ou rien n'est comparable.
- Les données ne sont qu'une partie de ce qui doit revenir.
