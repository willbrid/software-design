# Correction 11.1 — Exercice 3 : remplacer une simulation par un calcul

> Rappel de l'énoncé : écrire `Fanout`, qui donne le quantile de
> l'attente d'une requête qui attend N services, sans simuler.

La solution est dans `ex3` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Attendre N services indépendants**, c'est attendre le plus lent :
  P(max ≤ x) = P(un ≤ x)ᴺ.
- **On cherche donc le quantile q^(1/N) d'un seul service**, dans ses
  latences mesurées triées.
- **Une copie triée**, pas les échantillons de l'appelant.

## 1. La solution

```go
func Fanout(samples []time.Duration, n int, q float64) time.Duration {
    sorted := slices.Sorted(slices.Values(samples))
    target := math.Pow(q, 1/float64(n))
    for i, x := range sorted {
        if float64(i+1)/float64(len(sorted)) >= target {
            return x
        }
    }
    return sorted[len(sorted)-1]
}
```

## 2. Ce que le calcul dit

Pour que dix services donnent ensemble 99 % de requêtes rapides, chacun
doit en donner 0,99^(1/10) ≈ 99,9 %. Le 99e centile de l'écran est le
99,9e centile de chaque service. C'est pourquoi on fixe aux services
profonds des objectifs plus stricts qu'aux écrans qui les appellent.

## 3. Quand les services ne sont pas indépendants

Le calcul suppose que la lenteur de l'un ne dit rien de celle des
autres. Ce n'est pas le cas quand ils partagent quelque chose : la même
base, la même machine, le même réseau, le même ramasse-miettes qui
s'arrête au même moment. Deux effets opposés :

- s'ils sont **lents ensemble** (la base partagée sature), la requête
  attend un seul épisode lent au lieu d'en cumuler les chances : la
  queue de l'ensemble est **moins** mauvaise que le calcul ne le dit,
  mais chaque épisode touche toutes les requêtes à la fois ;
- s'ils se **gênent** (dix appels en parallèle chargent une ressource
  commune), chaque appel devient plus lent du fait des autres : la queue
  est **plus** mauvaise que le calcul.

Le calcul indépendant est un point de départ ; la mesure de la leçon 9.4
(le 99e centile de l'écran lui-même) tranche.

## Ce qu'il faut retenir

- Le maximum de N tirages se calcule avec la puissance N.
- Un objectif de bout en bout impose un objectif plus strict à chaque
  service.
- L'indépendance est une hypothèse, à vérifier par la mesure.
