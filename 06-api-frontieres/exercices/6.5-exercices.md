// Retirement serves Next until Sunset, and answers 410 Gone after it, and

// NewRetirement checks the plan: the sunset is not before the deprecation

## Exercice 3 — Refactoring : l'échéancier en double

*Niveau 3. Réécrire v1 ; les tests sont fournis.*

L'échéancier d'un prêt est calculé par `Plan` :

```go
// Plan returns the installments of l: the amount plus a flat interest,
// split in equal installments rounded to 5 FCFA, the last one taking what
// is left so that the sum is exact.
func Plan(l Loan) []Installment {
    total := l.AmountFCFA + l.AmountFCFA*MonthlyRatePct*int64(l.Months)/100
    each := total / int64(l.Months) / 5 * 5
    var out []Installment
    for m := 1; m <= l.Months; m++ {
        a := each
        if m == l.Months {
            a = total - each*int64(l.Months-1)
        }
        out = append(out, Installment{l.Granted.AddDate(0, m, 0), a})
    }
    return out
}
```

La version 2 l'utilise. La version 1, écrite avant que `Plan` arrondisse
à 5 FCFA et égalise la dernière échéance, a gardé son propre calcul :

```go
// V1 serves GET /v1/loans/{id}/schedule, as it was written before Plan
// rounded to 5 FCFA and evened the last installment.
func V1(loans map[int64]Loan) http.Handler {
    mux := http.NewServeMux()
    mux.HandleFunc("GET /v1/loans/{id}/schedule", func(w http.ResponseWriter, r *http.Request) {
        l, found := loan(loans, w, r)
        if !found {
            return
        }
        total := l.AmountFCFA + l.AmountFCFA*MonthlyRatePct*int64(l.Months)/100
        var out []InstallmentV1
        for m := 1; m <= l.Months; m++ {
            out = append(out, InstallmentV1{l.Granted.AddDate(0, m, 0).Format("02/01/2006"), total / int64(l.Months)})
        }
        reply(w, map[string]any{"schedule": out})
    })
    return mux
}
```

## Exercice 5 — Incident : les nairas en francs CFA

*Niveau 7. Un incident à mesurer, puis à corriger.*

Le lundi 9 novembre 2026, les premières tontines de Lagos ouvrent, en
nairas (NGN). La version 2 du relevé porte la devise. La version 1, que
lit encore l'application 4.x, est servie par la traduction de la
leçon :

```go
// Served is one statement served by the API: to which member, of which
// tontine currency, through which version, and what the answer said.
type Served struct {
    At       time.Time
    Member   string
    Currency string // of the member's tontine
    Version  string // "v1" or "v2"
    V1       api.StatementV1
    V2       api.StatementV2
}
```

```go
// Week replays 9 to 15 November 2026: 3 000 members in Douala and Dakar
// (XAF and XOF), 400 in Lagos (NGN). The application 5.x calls v2; the 4.x
// still installed calls v1, which is served by api.ToV1.
func Week() []Served {
    rnd := rand.New(rand.NewPCG(9, 11))
    var out []Served
    start := time.Date(2026, 11, 9, 0, 0, 0, 0, time.UTC)
    for i := range 3400 {
        currency := []string{"XAF", "XOF"}[i%2]
        if i >= 3000 {
            currency = "NGN"
        }
        old := rnd.Float64() < 0.35 // the share of 4.x still installed
        for day := range 7 {
            if rnd.Float64() > 0.5 {
                continue
            }
            s := api.StatementV2{
                Member:    fmt.Sprintf("m%04d", i),
                Balance:   api.Money{Amount: int64(500 * (1 + rnd.IntN(100))), Currency: currency},
                Penalties: api.Money{Amount: 0, Currency: currency},
            }
            at := start.AddDate(0, 0, day).Add(time.Duration(rnd.IntN(86400)) * time.Second)
            if old {
                out = append(out, Served{at, s.Member, currency, "v1", api.ToV1(s), s})
            } else {
                out = append(out, Served{at, s.Member, currency, "v2", api.StatementV1{}, s})
            }
        }
    }
    return out
}
```
