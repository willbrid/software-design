# Correction 10.3 — Exercice 3 : une facture en virgule flottante

> Rappel de l'énoncé : réécrire `Due` sans virgule flottante, avec le
> prorata exact et la taxe une fois sur la facture.

La solution est dans `ex3` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Deux lignes**, qui réutilisent les fonctions de la leçon.
- **La base d'abord**, proratisée sur la vraie durée, arrondie vers le
  bas ; **la taxe ensuite**, une fois.
- **La fonction ne peut plus produire de facture négative.**

## 1. La solution

```go
// Due is what an association of members owes when it takes, at from, an
// offer of price per member and per month, for the rest of the month
// [start, end), tax at rate included: the exact share of the month,
// rounded down, then the tax once on the invoice.
func Due(members int64, price money.Amount, rate money.Rate, start, end, from time.Time) money.Amount {
    base := money.Prorate(money.Amount(members)*price, start, end, from)
    return base + money.Tax(base, rate)
}
```

## 2. Les quatre défauts de l'ancienne version

| Défaut | Effet mesuré dans les tests |
|---|---|
| jours entamés comptés entiers (`math.Ceil`) | 10,5 jours facturés 11 |
| mois de 30 jours | janvier entier facturé 31/30 : 1 725 au lieu de 1 670 |
| taxe par membre, avant la multiplication | arrondis cumulés |
| virgule flottante | moitiés perdues |

Et un cinquième, que personne n'avait vu : la date avant le début du
mois (« before January ») donnait plus de jours que le mois, donc
1 781 FCFA.

## 3. La facture négative

Avec `from` après la fin du mois, `end.Sub(from)` est négatif : −2 jours,
arrondis par `math.Ceil` à −2, donc 175 × (−2) / 30 × 1,1925 × 8 =
−111,3, soit **−111 FCFA**. Une facture négative est un avoir. Selon le
code qui la suit, la plateforme aurait envoyé à l'opérateur un débit
négatif (refusé, ou pire, compris comme un virement), ou émis un avoir
que personne n'a demandé. `Prorate` borne le temps restant : rien avant
le début ne compte en plus, rien après la fin ne compte en moins.

## Ce qu'il faut retenir

- Une fonction de facturation se compose des fonctions d'argent
  testées, pas de calculs refaits sur place.
- Les bornes d'une période font partie du calcul.
- Un montant négatif est un avoir, qui se décide, pas une conséquence.
