# Correction 10.5 — Exercice 2 : ce qu'une entrée dit

> Rappel de l'énoncé : écrire `Detail`, qui décrit les champs changés,
> triés, sans secrets.

La solution est dans `ex2` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Tous les noms des deux côtés**, triés.
- **Un champ est inchangé s'il existe des deux côtés avec la même
  valeur**, ou n'existe d'aucun.
- **Un secret dit qu'il a changé**, jamais ses valeurs.

## 1. La solution

```go
func Detail(before, after map[string]string) string {
    names := map[string]bool{}
    for k := range before {
        names[k] = true
    }
    for k := range after {
        names[k] = true
    }
    var parts []string
    for _, k := range slices.Sorted(maps.Keys(names)) {
        old, hadOld := before[k]
        now, hasNew := after[k]
        if hadOld == hasNew && old == now {
            continue
        }
        if Secret[k] {
            parts = append(parts, k+": changed")
            continue
        }
        if !hadOld {
            old = "(none)"
        }
        if !hasNew {
            now = "(none)"
        }
        parts = append(parts, k+": "+old+" -> "+now)
    }
    return strings.Join(parts, "; ")
}
```

## 2. Pourquoi trier

Le détail fait partie du hachage. Si l'ordre des champs changeait d'une
exécution à l'autre (l'ordre d'une `map` en Go change à chaque
parcours), le même changement donnerait deux textes différents :
impossible de comparer deux entrées, de chercher « tous les changements
de `wallet` », ou de recalculer un détail pour vérifier une entrée. Un
texte stable est un texte qu'on peut relire et rehacher.

## 3. Le champ vide

Un champ ajouté avec une valeur vide (`note: (none) -> `) n'est pas un
champ inchangé : avant, il n'existait pas. Comparer seulement les
valeurs (`"" == ""`) le ferait disparaître. La campagne l'a montré :
la mutation qui oubliait l'existence a d'abord survécu, et le cas « empty
value added » a été ajouté.

## 4. Les secrets

`pin: changed` dit à l'auditeur qu'un code a été changé, et par qui (la
ligne d'entrée a l'acteur). Il ne lui dit rien qui permette de s'en
servir. La liste `Secret` est courte et explicite ; elle se complète
quand un nouveau champ sensible apparaît, et une revue la regarde à
chaque nouveau type d'action.

## Ce qu'il faut retenir

- Le détail d'une entrée est un texte stable, fait pour être relu et
  haché.
- Absent et vide ne sont pas la même chose.
- Un secret se mentionne, il ne s'écrit pas.
