# Correction 10.4 — Exercice 2 : rendre la place

> Rappel de l'énoncé : écrire `Leave`, qui supprime le membre et rend sa
> place au compteur.

La solution est dans `ex2` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **La suppression et le compteur dans la même transaction.**
- **Le compteur ne descend que si une ligne a été supprimée.**
- **Le départ d'un inconnu est une erreur**, qui ne touche à rien.

## 1. La solution

```go
func Leave(ctx context.Context, pool *pgxpool.Pool, tenant, member string) error {
    return pgx.BeginFunc(ctx, pool, func(tx pgx.Tx) error {
        tag, err := tx.Exec(ctx, `DELETE FROM members WHERE tenant_id = $1 AND id = $2`, tenant, member)
        if err != nil {
            return err
        }
        if tag.RowsAffected() == 0 {
            return ErrNotMember
        }
        _, err = tx.Exec(ctx, `UPDATE associations SET members = members - 1 WHERE id = $1`, tenant)
        return err
    })
}
```

## 2. Le départ d'un inconnu

Un départ qui ne supprime rien ne doit pas décrémenter : sinon, un
double clic sur « quitter », ou un départ rejoué par une file de
messages, rend une place qui n'a jamais été prise, et le compteur passe
sous le vrai nombre. L'association peut alors dépasser sa limite.

Renvoyer `ErrNotMember` plutôt que « rien à faire » laisse l'appelant
décider. Pour une requête de l'écran, c'est un `404`. Pour un message
rejoué, c'est le signe qu'il a déjà été traité, et l'appelant peut
l'ignorer en connaissance de cause (leçon 8.3).

## 3. La concurrence

Le test lance dix départs et dix adhésions en même temps. L'`UPDATE` du
départ et celui de l'adhésion verrouillent la même ligne de
l'association ; ils s'exécutent l'un après l'autre, et chacun part de la
valeur validée par l'autre. À la fin, le compteur égale le nombre de
lignes.

## Ce qu'il faut retenir

- Ce qui fait monter le compteur et ce qui le fait descendre sont
  symétriques, et transactionnels.
- On ne rend que ce qu'on a pris.
- Une erreur précise vaut mieux qu'un silence : l'appelant sait quoi en
  faire.
