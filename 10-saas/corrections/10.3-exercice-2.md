# Correction 10.3 — Exercice 2 : partager une somme

> Rappel de l'énoncé : écrire `Split`, qui partage une somme selon des
> poids, au franc près.

La solution est dans `ex2` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Chaque part reçoit d'abord la partie entière** de sa part exacte.
- **Les francs qui restent vont aux plus grands restes**, à égalité à la
  première part.
- **Une somme négative se partage comme son opposée**, au signe près.

## 1. La solution

```go
func Split(total money.Amount, weights []int64) []money.Amount {
    parts := make([]money.Amount, len(weights))
    var sum int64
    for _, w := range weights {
        sum += w
    }
    if sum == 0 {
        return parts
    }
    if total < 0 {
        for i, p := range Split(-total, weights) {
            parts[i] = -p
        }
        return parts
    }
    left := total
    remainders := make([]int64, len(weights))
    for i, w := range weights {
        parts[i] = money.Amount(int64(total) * w / sum)
        remainders[i] = int64(total) * w % sum
        left -= parts[i]
    }
    order := make([]int, len(weights))
    for i := range order {
        order[i] = i
    }
    slices.SortFunc(order, func(a, b int) int {
        if remainders[a] != remainders[b] {
            return cmp.Compare(remainders[b], remainders[a])
        }
        return a - b // a tie goes to the first part
    })
    for _, i := range order[:left] {
        parts[i]++
    }
    return parts
}
```

## 2. Pourquoi pas l'arrondi au plus proche

Avec trois poids égaux et 100 FCFA, chaque part exacte vaut 33,33 :
l'arrondi au plus proche donne 33 + 33 + 33 = 99. Avec 200 FCFA, 66,67
chacune : 67 + 67 + 67 = 201. L'arrondi de chaque part est juste ; la
somme ne l'est pas, et l'écart grandit avec le nombre de parts.

La méthode des plus grands restes garantit les deux propriétés à la
fois : la somme est exacte (on distribue exactement les francs qui
manquent), et chaque part est à moins d'un franc de sa part exacte (elle
reçoit sa partie entière, plus au plus un franc).

## 3. Les égalités

Six poids égaux et 5 FCFA : chaque part a le même reste. Qui reçoit les
francs ? La règle dit « la première part » ; elle aurait pu dire « la
plus grande tontine » ou « tirer au sort chaque mois ». L'important est
qu'elle soit **déterministe** : la même facture partagée deux fois donne
les mêmes parts. La première version triait avec un tri stable sans
nommer la règle ; la campagne n'arrivait pas à distinguer un tri stable
d'un tri qui ne l'est pas. La règle est maintenant écrite dans la
comparaison, et la mutation « égalité au dernier » est tuée.

## Ce qu'il faut retenir

- Arrondir chaque part ne donne pas le total.
- Les plus grands restes donnent le total, et des parts justes au franc.
- Une égalité se tranche par une règle écrite.
