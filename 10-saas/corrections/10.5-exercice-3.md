# Correction 10.5 — Exercice 3 : un rôle donné, et une ligne de journal

> Rappel de l'énoncé : réécrire `Grant` pour que le rôle et son entrée
> d'audit soient écrits dans la même transaction.

La solution est dans `ex3` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Le rôle, puis l'entrée, dans la même fonction de transaction.**
- **Un échec n'écrit rien**, ni rôle ni entrée.
- **La ligne de journal technique** reste utile pour les échecs, mais
  elle n'est pas l'audit.

## 1. La solution

```go
// Grant gives role in tenant to user, on behalf of actor: the grant and
// its entry in the journal are written in one transaction.
func Grant(ctx context.Context, pool *pgxpool.Pool, tenant, actor, user, role string) error {
    return pgx.BeginFunc(ctx, pool, func(tx pgx.Tx) error {
        if _, err := tx.Exec(ctx, `INSERT INTO grants (tenant_id, user_id, role) VALUES ($1, $2, $3)`, tenant, user, role); err != nil {
            return err
        }
        return audit.Record(ctx, tx, audit.Entry{Tenant: tenant, Actor: actor, Action: "role.grant",
            Object: user, Detail: "role: (none) -> " + role, At: time.Now()})
    })
}
```

## 2. Ce que l'ancienne version écrivait

`log.Printf` écrivait dans le journal technique, après la transaction,
le succès **et** l'échec. Trois défauts : l'entrée n'existe pas si le
processus meurt entre les deux ; elle est dans un journal qu'on tourne
et supprime ; et elle n'est pas chaînée.

Les tentatives échouées (un rôle qui n'existe pas, un rôle déjà donné)
sont pourtant utiles : elles disent qu'une présidente a essayé, et
pourquoi elle n'a pas pu. Elles ont leur place dans le journal technique
(leçon 9.4), avec l'identifiant de la requête, ou, si elles comptent
pour la sécurité (des refus d'autorisation répétés), dans une entrée
d'audit à part, `role.grant.refused`, écrite dans sa propre transaction.
Ce qui ne doit jamais arriver : une entrée `role.grant` pour un rôle qui
n'a pas été donné.

## Ce qu'il faut retenir

- L'audit d'une action s'écrit avec l'action.
- Le journal technique raconte ; le journal d'audit prouve.
- Un échec est un autre fait, avec un autre nom.
