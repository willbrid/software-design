# Correction 10.4 — Exercice 5 : les associations pleines à moitié

> Rappel de l'énoncé : un compteur qui monte à chaque adhésion et ne
> descend jamais ; auditer l'année, rejouer, rédiger.

L'audit et le rejeu sont dans `ex5` du module de correction, verts sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **599 adhésions refusées à tort**, dans 78 associations sur 100.
- **380 membres manquent au 31 décembre** : 4 273 au lieu de 4 653.
- **Avec un départ qui rend la place**, 228 refus, tous justes : ces
  associations étaient vraiment pleines.

## 1. L'audit

```go
func Audit(start map[string]int, events, refused []Event) Report {
    wasRefused := map[Event]bool{}
    for _, e := range refused {
        wasRefused[e] = true
    }
    members := map[string]int{}
    for t, n := range start {
        members[t] = n
    }
    r := Report{Refused: len(refused)}
    wrong := map[string]bool{}
    for _, e := range events {
        switch {
        case e.Leave:
            members[e.Tenant]--
        case wasRefused[e]:
            if members[e.Tenant] < Limit {
                r.WronglyRefused++
                wrong[e.Tenant] = true
            }
        default:
            members[e.Tenant]++
        }
    }
    r.Associations = len(wrong)
    for _, n := range members {
        r.Members += n
    }
    return r
}
```

L'audit ne fait pas confiance au compteur : il rejoue le **vrai** nombre
de membres à partir du journal, et juge chaque refus avec ce nombre.

## 2. Les chiffres, et le rejeu

`cmd/journal` audite l'année telle qu'elle s'est passée, puis rejouée
avec `Fixed` :

```text
2026: 100 associations of the free offer (50 members), 2546 asked to join, 665 left

                                 refused  wrongly refused   associations   members 31 Dec
as it ran: leaves keep the seat       608              599             78             4273
leaves give the seat back            228                0              0             4653
```

- **Comme elle s'est passée** : 608 refus, dont 599 alors que
  l'association avait moins de 50 membres. Les 9 autres étaient justes,
  par chance. Chaque départ laissait une place fantôme ; 78 associations
  ont fini l'année « pleines » avec moins de 50 membres.
- **Les départs qui rendent la place** : 228 refus, tous justes. Les 380
  personnes de différence sont des membres que les associations
  voulaient, et qu'elles n'ont pas eus.

## 3. La cause

**En une phrase** : le départ supprimait le membre sans rendre sa place
au compteur ; chaque départ réduisait pour toujours la capacité de
l'association.

**La cause de la cause** : le compteur avait été ajouté pour tenir la
limite en concurrence (la leçon), mais seulement sur le chemin de
l'adhésion. Personne n'avait fait la liste de tout ce qui change le
nombre de membres : départ, exclusion, fusion de comptes, suppression
par le support. Et rien ne comparait le compteur au vrai nombre.

## 4. Le compte rendu

1. **Quoi** : en 2026, 599 demandes d'adhésion ont été refusées à tort
   dans 78 associations gratuites, qui affichaient « 50 membres » en en
   ayant moins ; 380 membres manquent au 31 décembre.
2. **Cause** : le départ d'un membre ne rendait pas sa place au compteur
   de l'offre.
3. **Détection** : par les présidentes, en décembre, plusieurs mois après
   les premiers refus ; aucune alerte.
4. **Correction** : les compteurs sont recalculés depuis la table des
   membres ; le départ rend la place dans la même transaction (exercice
   2) ; les personnes refusées reçoivent une nouvelle invitation.
5. **Prévention** : tout chemin qui ajoute ou retire un membre passe par
   deux fonctions (adhérer, partir) ; un travail de nuit compare chaque
   compteur au vrai nombre et alerte au premier écart ; les refus pour
   limite sont comptés par association, et une association refusée alors
   qu'elle a moins de membres que sa limite déclenche une alerte.
