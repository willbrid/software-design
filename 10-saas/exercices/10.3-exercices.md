## Exercice 1 — Compréhension : où est l'erreur ?

*Niveau 1. Aucune ligne de code à écrire.*

### 1.a — Six situations

Pour chacune, dis quelle règle de la leçon manque, et ce qu'elle aurait
changé.

1. Le montant d'une facture est stocké dans une colonne `double
   precision`.
2. Une remise de 10 % est calculée sur chaque ligne, arrondie, puis
   additionnée.
3. Une association passe à l'offre supérieure le 1er mars à 8 h ; on lui
   facture 31 jours sur 30.
4. Le travail de débit génère une clé avec `uuid.New()` avant chaque
   appel à l'opérateur.
5. Une facture de mars contenait une erreur ; elle a été corrigée en
   base en juin.
6. Le rapprochement montre chaque jour quelques francs d'écart ;
   l'équipe a pris l'habitude de l'ignorer.

### 1.b — Trois pourquoi

1. Pourquoi l'erreur de la virgule flottante tombe-t-elle justement sur
   les moitiés ?
2. Pourquoi le prorata arrondit-il vers le bas, et la taxe à la moitié ?
3. Pourquoi la clé du débit doit-elle venir de la facture, et pas de la
   requête ?

### 1.c — Le sens des mesures

Dans `cmd/rounding`, la virgule flottante ne se trompe jamais vers le
haut : 121 francs de moins, aucun de plus. Est-ce une loi, ou un hasard
de ces chiffres ? Que faudrait-il pour qu'elle se trompe vers le haut ?

## Exercice 2 — Code : partager une somme

*Niveau 2. Écrire une fonction ; les tests sont fournis.*

Une fédération reçoit une facture globale, à partager entre ses tontines
selon leur nombre de membres. La somme des parts doit tomber juste au
franc :

```go
// Split shares total between parts in proportion to weights. The parts
// add up to total exactly, each is within one franc of its exact share,
// and the francs left by rounding go to the largest remainders, the
// first part winning a tie. A zero sum of weights gives zero parts.
func Split(total money.Amount, weights []int64) []money.Amount {
    return make([]money.Amount, len(weights))
```

## Exercice 3 — Refactoring : une facture en virgule flottante

*Niveau 3. Réécrire une fonction ; les tests sont fournis.*

La première facture d'une association qui prend une offre en cours de
mois est calculée ainsi :

```go
// Due is what an association of members owes when it takes, at from, an
// offer of price per member and per month, for the rest of the month
// [start, end), tax at rate included. Rewrite it with the rules of the
// lesson: no floating point, the exact share of the month rounded down,
// the tax once on the invoice.
func Due(members int64, price money.Amount, rate money.Rate, start, end, from time.Time) money.Amount {
    days := math.Ceil(end.Sub(from).Hours() / 24)
    perMember := float64(price) * days / 30
    perMember = perMember * (1 + float64(rate)/10000)
    return money.Amount(math.Round(perMember * float64(members)))
}
```

signature :

## Exercice 4 — Design : la facture à l'usage

*Niveau 4. Aucune ligne de code : une page.*

La plateforme ajoute une offre : 5 000 FCFA par mois, plus 10 FCFA par
SMS de rappel envoyé au-delà de 200. Conçois le cycle du mois :

- comment chaque SMS est compté, une seule fois, même si le service
  d'envoi renvoie ses confirmations deux fois ;
- quand le mois se ferme, et ce qui arrive aux SMS confirmés après ;
- comment la facture est émise, numérotée, débitée ;
- ce qui se passe quand le débit est refusé (fonds insuffisants), le
  premier jour, puis au bout d'une semaine, puis d'un mois ;
- ce que voit la trésorière, avant la fin du mois, sur ce qu'elle va
  payer.

## Exercice 5 — Incident : le 1er novembre

*Niveau 7. Un incident à mesurer, puis à rejouer comme il aurait dû
être fait.*

Le dimanche 1er novembre 2026, le travail de débit s'arrête au milieu.
L'astreinte le relance à 9 h, du début. Le lundi, le support reçoit des
dizaines d'appels de trésorières débitées deux fois. La journée se
rejoue ainsi :

```go
// November plays 1 November 2026: the job debits the invoices with key,
// the operator loses 3 % of its answers, and the job dies after 1200
// invoices; at 9:00 someone runs it again, from the start. It returns
// the operator, whose debits are the statement of the month.
func November(key collect.Key) *operator.Operator {
    r := rand.New(rand.NewPCG(2026, 11))
    op := operator.New(func() bool { return r.IntN(100) < 3 })
    invoices := Invoices()
    collect.Run(op, invoices[:1200], key)
    collect.Run(op, invoices, key)
    return op
}
```

```go
// PerAttempt is the key the job used: a new one for every call, made by
// the HTTP library of the operator.
func PerAttempt() collect.Key {
    n := 0
    return func(collect.Invoice, int) string {
        n++
        return fmt.Sprintf("req-%06d", n)
    }
}
```
