## Exercice 1 — Compréhension : quel défaut, quelle règle ?

*Niveau 1. Aucune ligne de code à écrire.*

### 1.a — Six situations

Pour chacune, dis quelle règle de la leçon manque, et ce qu'elle aurait
changé.

1. La présidente d'une tontine, simple membre d'une autre, change les
   réglages de la seconde.
2. L'ancien trésorier, battu aux élections de janvier, verse encore en
   mars.
3. Un membre exclu à 14 h envoie des invitations jusqu'à 14 h 50.
4. Une nouvelle route `DELETE /members/{id}` est appelable par tout le
   monde, parce qu'elle ne vérifie rien.
5. Le rôle « commissaire aux comptes » peut enregistrer des cotisations,
   parce que la route vérifie `role != "member"`.
6. Le support de la plateforme a un rôle « admin » qui passe toutes les
   vérifications de toutes les associations.

### 1.b — Trois pourquoi

1. Pourquoi corriger seulement les « trésoriers refusés chez eux » de la
   section 2 aggrave-t-il le problème ?
2. Pourquoi le jeton porte-t-il l'identité, mais pas les rôles ?
3. Pourquoi la durée du cache des rôles est-elle une exigence à discuter
   avec les associations, et pas un réglage technique ?

### 1.c — Le sens des mesures

Dans `cmd/revoke`, le cache de 30 s donne 100 lectures de l'annuaire par
heure et par personne, et pas 120 (3 600 s divisées par 30 s). Pourquoi ?
Et pourquoi le plus long délai mesuré est-il de 29 s, et pas de 30 ?

## Exercice 3 — Refactoring : des noms de rôles dans chaque route

*Niveau 3. Réécrire une fonction ; les tests sont fournis.*

Les routes de l'écran de la trésorière vérifient elles-mêmes les noms des
rôles. Les associations demandent trois nouveaux rôles : la commissaire
aux comptes (lit et exporte), le trésorier adjoint (enregistre et lit,
ne verse jamais), l'invité (n'a encore rien accepté, ne fait rien) :

```go
// Allowed says whether a holder of role may call route.
func Allowed(role string, route Route) bool {
    switch route {
    case ListMembers:
        return true
    case Invite, Settings, Approve:
        return role == "president"
    case Record:
        return role != "member"
    case Report, Export:
        return role == "treasurer" || role == "president"
    case Execute:
        return role == "treasurer"
    }
    return false
}
```

## Exercice 5 — Incident : les versements de l'été 2026

*Niveau 7. Un incident à mesurer, puis à rejouer comme il aurait dû
être fait.*

En novembre 2026, le rapprochement annuel de trois associations ne
tombe pas juste. L'équipe exporte les mandats des cinq dernières années
et le journal des versements de 2026 :

```go
// Year2026 returns the offices held from 2022 to 2026, the grants the
// platform held on 31 October 2026 (each election gave roles, none took
// any back), and the payouts executed from 1 January to 31 October 2026.
func Year2026() ([]Office, []authz.Grant, []Payout) {
    var offices []Office
    var grants []authz.Grant
    member := func(tenant string, m int) string { return fmt.Sprintf("%s-m%02d", tenant, m) }
    for a := 1; a <= 30; a++ {
        tenant := fmt.Sprintf("t%03d", a)
        for i, year := 0, 2022; year <= 2026; i, year = i+1, year+1 {
            bureau := map[string][]int{"president": {3 * i}, "treasurer": {3*i + 1, 3*i + 2}}
            if tenant == "t007" && year == 2024 {
                bureau["president"] = []int{4} // the treasurer of 2023
            }
            for _, role := range []string{"president", "treasurer"} {
                for _, m := range bureau[role] {
                    offices = append(offices, Office{tenant, role, member(tenant, m), election(year), election(year + 1)})
                    grants = append(grants, authz.Grant{User: member(tenant, m), Tenant: tenant, Role: role})
                }
            }
        }
    }
    holder := func(tenant, role string, at time.Time, seat int) string {
        var in []string
        for _, o := range offices {
            if o.Tenant == tenant && o.Role == role && !at.Before(o.From) && at.Before(o.To) {
                in = append(in, o.User)
            }
        }
        return in[seat%len(in)]
    }
    var payouts []Payout
    for a := 1; a <= 30; a++ {
        tenant := fmt.Sprintf("t%03d", a)
        for month := time.January; month <= time.October; month++ {
            for k, day := range []int{5, 20} {
                at := time.Date(2026, month, day, 10, 0, 0, 0, time.UTC)
                payouts = append(payouts, Payout{tenant, holder(tenant, "treasurer", at, k), holder(tenant, "president", at, 0), at, 100000 + 5000*int64(month)})
            }
        }
    }
    // What the audit of November found, in the journal like the rest.
    for k := range 9 {
        at := time.Date(2026, 8, 3+7*k, 22, 0, 0, 0, time.UTC)
        payouts = append(payouts, Payout{"t007", "t007-m04", "t007-m04", at, 200000})
    }
    for _, f := range []struct{ tenant, who string }{{"t013", "t013-m02"}, {"t021", "t021-m07"}} {
        for k := range 6 {
            at := time.Date(2026, 9, 2+5*k, 21, 0, 0, 0, time.UTC)
            payouts = append(payouts, Payout{f.tenant, f.who, f.tenant + "-m12", at, 150000})
        }
    }
    return offices, grants, payouts
}
```
