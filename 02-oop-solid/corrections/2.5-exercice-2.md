# Correction 2.5 — Exercice 2 : le service d'octroi de crédit

> Rappel de l'énoncé : un métier qui consulte un bureau de crédit (HTTP),
> l'historique des comptes (PostgreSQL), un barème (YAML), et notifie par
> SMTP — avec ses ports, quatre adaptateurs, une racine de composition, un
> test d'architecture et une batterie.

Sept paquets — `octroi`, `bureau`, `historique`, `bareme`,
`notification`, `montage`, `archi` —, verts sous `go vet ./...` et
`go test -race -count=1 ./...`. Campagne de dix-huit modifications, 18/18
après deux passes. Le barème est lu avec `gopkg.in/yaml.v3`, pour que le test
d'architecture ait une vraie bibliothèque tierce à interdire.

## 1. Le métier et ses ports

Un port par source, chacun avec les seules méthodes qu'`octroi` appelle, et
le vocabulaire d'erreurs qui leur est commun :

```go
// Le vocabulaire des ports. Un adaptateur qui rend ces erreurs importe ce
// paquet : c'est l'exception legitime de la lecon 2.4.
var (
    ErrBureauIndisponible = errors.New("octroi : bureau de credit indisponible")
    ErrProfilInconnu      = errors.New("octroi : profil inconnu")
)

// Incident est un incident de paiement declare au bureau de credit.
type Incident struct {
    Date    time.Time
    Montant int64
}

// Demande est une demande de credit.
type Demande struct {
    Demandeur  string
    Profil     string
    Mensualite int64 // en centimes
}

// Decision est la reponse rendue au demandeur.
type Decision struct {
    Accord bool
    Motif  string
}

// Bureau lit les incidents de paiement d'un demandeur.
type Bureau interface {
    Incidents(demandeur string) ([]Incident, error)
}

// Historique lit, dans la tenue de compte de la banque, ce qui fait le revenu
// regulier et les engagements en cours.
type Historique interface {
    RevenusMensuels(demandeur string, mois int) ([]int64, error)
    MensualitesEnCours(demandeur string) (int64, error)
}

// Bareme rend le taux d'endettement maximal d'un profil, en points de base :
// 3300 pour 33 %.
type Bareme interface {
    TauxMax(profil string) (int64, error)
}

// Notificateur ecrit la decision au demandeur.
type Notificateur interface {
    Notifier(demandeur string, d Decision) error
}

// Service est le metier de l'octroi.
type Service struct {
    Bureau       Bureau
    Historique   Historique
    Bareme       Bareme
    Notificateur Notificateur
}
```

Deux choix méritent d'être dits.

- **Le barème rend des points de base**, pas un `float64`. « 33 % » devient
  3300, et la comparaison se fait en entiers, sans arrondi.
- **`Historique` a deux méthodes**, `Bureau` une seule. Le critère est
  l'usage (leçon 2.5, section 5), pas la taille : les deux lectures de
  l'historique viennent de la même source et changent ensemble.

La règle, en entier :

```go
func (s Service) regle(d Demande, maintenant time.Time) (Decision, error) {
    incidents, err := s.Bureau.Incidents(d.Demandeur)
    if err != nil {
        return Decision{}, err
    }
    limite := maintenant.AddDate(0, -FenetreIncidents, 0)
    for _, i := range incidents {
        if i.Date.After(limite) {
            return Decision{Motif: "incident de paiement de moins de 24 mois"}, nil
        }
    }
    revenus, err := s.Historique.RevenusMensuels(d.Demandeur, MoisDeRevenus)
    if err != nil {
        return Decision{}, err
    }
    if len(revenus) < MoisDeRevenus {
        return Decision{Motif: "moins de six mois de revenus"}, nil
    }
    // Le revenu regulier est le PLUS PETIT des six : un mois exceptionnel ne
    // doit pas faire passer un dossier.
    regulier := revenus[0]
    for _, r := range revenus[1:] {
        regulier = min(regulier, r)
    }
    enCours, err := s.Historique.MensualitesEnCours(d.Demandeur)
    if err != nil {
        return Decision{}, err
    }
    taux, err := s.Bareme.TauxMax(d.Profil)
    if err != nil {
        return Decision{}, err
    }
    if (enCours+d.Mensualite)*10_000 > taux*regulier {
        return Decision{Motif: "taux d'endettement au-dessus du bareme"}, nil
    }
    return Decision{Accord: true}, nil
}
```

La preuve que le métier ne connaît aucune technologie, demandée par la
question 1 :

```

database/sql       octroi=0 montage=1
net/smtp           octroi=0 montage=1
gopkg.in/yaml.v3   octroi=0 montage=1
```

`octroi` a 60 dépendances, toutes de la bibliothèque standard ; l'adaptateur

## 2. Les quatre adaptateurs

Chacun **traduit** — c'est son seul travail. Le bureau de crédit, par
exemple, transforme un 404 en « aucun incident » et tout autre échec en
`ErrBureauIndisponible` :

```go
// Incidents traduit la reponse du bureau dans le vocabulaire d'octroi : un
// 404 veut dire « inconnu du bureau », donc aucun incident ; tout le reste qui
// n'est pas un 200 veut dire « indisponible ».
func (c Client) Incidents(demandeur string) ([]octroi.Incident, error) {
    r, err := c.HTTP.Get(c.Base + "/incidents?person=" + url.QueryEscape(demandeur))
    if err != nil {
        return nil, fmt.Errorf("%w : %v", octroi.ErrBureauIndisponible, err)
    }
    defer r.Body.Close()
    switch {
    case r.StatusCode == http.StatusNotFound:
        return nil, nil
    case r.StatusCode != http.StatusOK:
        return nil, fmt.Errorf("%w : statut %d", octroi.ErrBureauIndisponible, r.StatusCode)
    }
    var brut []incidentJSON
    if err := json.NewDecoder(r.Body).Decode(&brut); err != nil {
        return nil, fmt.Errorf("%w : reponse illisible : %v", octroi.ErrBureauIndisponible, err)
    }
    out := make([]octroi.Incident, 0, len(brut))
    for _, i := range brut {
        out = append(out, octroi.Incident{Date: i.Date, Montant: i.Montant})
    }
    return out, nil
}
```

Le barème valide le fichier entier au chargement, et refuse un taux hors de
[1, 10 000] — la faute visée est un zéro de trop, qui ferait accorder des
crédits à 330 % d'endettement :

```go
// Charger lit et valide le fichier : un taux par profil, en points de base,
// entre 1 et 10 000.
func Charger(chemin string) (*Fichier, error) {
    b, err := os.ReadFile(chemin)
    if err != nil {
        return nil, err
    }
    var brut struct {
        Taux map[string]int64 `yaml:"taux_max_points_de_base"`
    }
    if err := yaml.Unmarshal(b, &brut); err != nil {
        return nil, fmt.Errorf("bareme : %w", err)
    }
    if len(brut.Taux) == 0 {
        return nil, fmt.Errorf("bareme : aucun profil dans %s", chemin)
    }
    for p, t := range brut.Taux {
        if t < 1 || t > 10_000 {
            return nil, fmt.Errorf("bareme : profil %q, taux %d hors de [1, 10000]", p, t)
        }
    }
    return &Fichier{taux: brut.Taux}, nil
}
```

L'historique, sur PostgreSQL, **compile mais n'est jamais exécuté** : il n'y a
pas de base dans ce module. C'est la limite de l'exercice, et il faut la
dire : ses requêtes SQL ne sont vérifiées par rien ici. En production, il
lui faut une batterie du port `Historique` passée contre une vraie base
jetable — c'est le seul adaptateur dont le contrat ne se vérifie pas avec une
doublure.

## 3. La racine de composition

```go
// Assembler cable les quatre adaptateurs sur le metier.
func Assembler(c Config, db *sql.DB, h *http.Client) (octroi.Service, error) {
    b, err := bareme.Charger(c.CheminBareme)
    if err != nil {
        return octroi.Service{}, err
    }
    return octroi.Service{
        Bureau:     bureau.Client{Base: c.BureauURL, HTTP: h},
        Historique: historique.Postgres{DB: db},
        Bareme:     b,
        Notificateur: notification.SMTP{
            Serveur: c.ServeurSMTP, Expediteur: "credit@banque.example",
            Adresse: c.Adresse, Envoyer: smtp.SendMail,
        },
    }, nil
}
```

**Si un adaptateur cesse de satisfaire son port, c'est ici que ça casse** —
et la question 7 le mesure. Mais la campagne a montré qu'elle ne suffit
pas : un port câblé à `nil` compile. D'où le test :

```go
// TestToutEstCable : le compilateur verifie le type de chaque port cable, pas
// que chaque port l'est.
func TestToutEstCable(t *testing.T) {
    s, err := Assembler(Config{CheminBareme: "../bareme/testdata/bareme.yaml"}, nil, http.DefaultClient)
    if err != nil {
        t.Fatal(err)
    }
    v := reflect.ValueOf(s)
    for i := range v.NumField() {
        if v.Field(i).IsNil() {
            t.Errorf("le port %s n'est pas cable", v.Type().Field(i).Name)
        }
    }
}
```

## 4. Le test d'architecture

```go
const module = "exemple/c25/ex2/"

// interdits : ce que le metier ne doit jamais tirer, directement ou non.
var interdits = map[string][]string{
    "octroi": {
        "net/http", "database/sql", "net/smtp", "gopkg.in/yaml.v3",
        module + "bureau", module + "historique", module + "bareme", module + "notification",
    },
}

// infrastructure : les paquets qui ont le droit de tout importer.
var infrastructure = map[string]bool{
    "bureau": true, "historique": true, "bareme": true, "notification": true,
    "montage": true, "archi": true,
}

func violations(t *testing.T, paquet string, refus []string) []string {
    t.Helper()
    sortie, err := exec.Command("go", "list", "-deps", paquet).Output()
    if err != nil {
        t.Fatalf("go list %s : %v", paquet, err)
    }
    deps := map[string]bool{}
    for _, d := range strings.Fields(string(sortie)) {
        deps[d] = true
    }
    var out []string
    for _, r := range refus {
        if deps[r] {
            out = append(out, r)
        }
    }
    return out
}

func TestLeMetierNeTireAucuneTechnologie(t *testing.T) {
    for p, refus := range interdits {
        for _, v := range violations(t, "../"+p, refus) {
            t.Errorf("%s depend de %s", p, v)
        }
    }
}

// TestLeTestVoitUneVraieViolation : l'adaptateur HTTP tire net/http, et c'est
// une vraie dependance, pas une chaine ecrite pour l'occasion. Il « depend »
// aussi de lui-meme : go list -deps compte le paquet parmi ses dependances.
func TestLeTestVoitUneVraieViolation(t *testing.T) {
    got := violations(t, "../bureau", interdits["octroi"])
    if strings.Join(got, " ") != "net/http "+module+"bureau" {
        t.Fatalf("violations de bureau : %v", got)
    }
}

func TestLaListeCouvreToutLeModule(t *testing.T) {
    sortie, err := exec.Command("go", "list", "../...").Output()
    if err != nil {
        t.Fatal(err)
    }
    for _, p := range strings.Fields(string(sortie)) {
        nom := strings.TrimPrefix(p, module)
        if !infrastructure[nom] && interdits[nom] == nil {
            t.Errorf("%s n'est ni de l'infrastructure ni du metier", nom)
        }
    }
}
```

Le test négatif tire sur une **vraie** violation : l'adaptateur `bureau`,
qui importe réellement `net/http`. Et il m'a appris une chose en tirant : il
a rendu **deux** violations, pas une — `net/http` et `bureau` lui-même.
`go list -deps` compte le paquet parmi ses propres dépendances. Sans
conséquence pour `octroi`, qui ne s'interdit pas lui-même, mais une liste
d'interdits qui contiendrait le paquet testé serait toujours rouge.

## 5. La batterie du port `Bureau`

Écrite dans `octroi`, qui déclare le port :

```go
// JeuBureau est ce que la batterie du port Bureau demande : un bureau qui
// connait Awa (deux incidents), Bala (aucun), et un bureau en panne.
type JeuBureau struct {
    Nouveau func(incidents map[string][]Incident) Bureau
    EnPanne func() Bureau
}

var (
    ancien  = time.Date(2021, time.June, 1, 0, 0, 0, 0, time.UTC)
    recent  = time.Date(2025, time.November, 3, 0, 0, 0, 0, time.UTC)
    fichier = map[string][]Incident{"awa": {{Date: ancien, Montant: 120_000}, {Date: recent, Montant: 45_000}}}
)

// VerifierBureau passe les trois clauses du port Bureau. Elle vit ici : c'est
// octroi qui declare le port, c'est lui qui dit ce qu'il en attend.
func VerifierBureau(j JeuBureau) []string {
    var out []string
    b := j.Nouveau(fichier)
    is, err := b.Incidents("awa")
    if err != nil || len(is) != 2 || !is[0].Date.Equal(ancien) || !is[1].Date.Equal(recent) || is[1].Montant != 45_000 {
        out = append(out, fmt.Sprintf("clause 1 : les incidents d'awa = %v, %v", is, err))
    }
    if is, err := b.Incidents("bala"); err != nil || len(is) != 0 {
        out = append(out, fmt.Sprintf("clause 2 : un demandeur sans incident rend %v, %v — attendu rien et aucune erreur", is, err))
    }
    if _, err := j.EnPanne().Incidents("awa"); !errors.Is(err, ErrBureauIndisponible) {
        out = append(out, fmt.Sprintf("clause 3 : un bureau en panne rend %v, pas ErrBureauIndisponible", err))
    }
    return out
}
```

Le relevé : l'adaptateur HTTP, branché sur un `httptest.Server`, et la
doublure des tests du métier **tiennent les trois clauses**. Et un fautif
écrit pour la vérifier — un bureau qui rend « aucun incident » quand il est en
panne, c'est-à-dire qui laisse passer un dossier à risque — en casse une :

```go
// avaleur rend « aucun incident » quand le bureau est en panne : un dossier
// a risque passe. La batterie doit le voir.
type avaleur struct{}

func (avaleur) Incidents(string) ([]Incident, error) { return nil, nil }

func TestLaBatterieVoitUnePanneAvalee(t *testing.T) {
    echecs := VerifierBureau(JeuBureau{
        Nouveau: func(is map[string][]Incident) Bureau { return bureau(is) },
        EnPanne: func() Bureau { return avaleur{} },
    })
    if len(echecs) != 1 || !strings.HasPrefix(echecs[0], "clause 3 ") {
        t.Fatalf("%v", echecs)
    }
}
```

## 6. Le sondage sur mes propres ports

Le sondage de la leçon cherche `pkg.Interface` ; ici les ports sont déclarés
et appelés dans le même paquet. J'en ai écrit la variante, qui lit les champs

```go
// TestChaqueMethodeDePortEstAppelee : le sondage de la lecon, applique aux
// ports qu'octroi declare. Une methode qu'octroi n'appelle pas n'a rien a
// faire dans son port.
func TestChaqueMethodeDePortEstAppelee(t *testing.T) {
    ports, _, appels := lire(t)

    for p := range ports {
        noms = append(noms, p)

                t.Logf("%-12s %-20s appelee", p, m)

                t.Errorf("%s.%s : declaree, jamais appelee par octroi", p, m)
            }
        }
    }
    if len(noms) != 4 {
        t.Fatalf("%d ports lus, attendu 4 : %v", len(noms), noms)

}
```

Les quatre modifications exigées par l'énoncé sont tuées, chacune par le
garde prévu pour elle :

| Modification | Tuée par |
|---|---|
| `octroi` importe un adaptateur | le test d'architecture |
| un `*http.Response` dans un type du port | le test d'architecture — `octroi` importe alors `net/http` |
| `octroi` retiré de la liste du test | le garde de la liste |
| une méthode de port que personne n'appelle | le sondage de la question 6 |

La deuxième était impossible telle quelle — changer la signature d'un port
casse toutes ses implémentations — et je l'ai jouée sous la forme qui compile
et qui arrive vraiment : un champ `Brut *http.Response` ajouté à
`Incident`, « pour le débogage ». Un type de l'adaptateur entre dans le métier
par une structure, pas par une méthode.

Deux modifications ne compilaient pas — une variable devenue inutilisée, un
import devenu inutilisé — et ont été rejouées sous une forme qui compile
(`enCours*0`, un port câblé à `nil`). Une modification qui ne compile pas
n'a pas été jouée.

Le survivant, « batterie `Bureau` : clause 3 muette », **réclame un test** :
aucune implémentation ne rendait autre chose que la bonne sentinelle en
panne. C'est le fautif de la question 5.

## Ce qu'il faut retenir

| | |
|---|---|
| ⚫ | Un port par source, avec les seules méthodes que le métier appelle. Le critère est l'usage : `Historique` a deux méthodes, et c'est juste. |
| ⚫ | Le métier tire 60 dépendances standard ; un seul adaptateur HTTP en tire 200. `go list -deps` le prouve en une ligne. |
| ⚫ | Un adaptateur traduit : statuts HTTP vers sentinelles, fichier vers taux validés. La validation à la frontière refuse le fichier entier. |
| ⚫ | Un adaptateur qu'on ne peut pas exécuter ici — l'historique SQL — n'est vérifié par rien. Il faut le dire, et lui donner une batterie contre une base jetable. |
| ⚫ | La racine de composition casse quand un adaptateur ne satisfait plus son port ; elle ne casse pas quand un port est câblé à `nil`. Un test le fait. |
| ⚫ | `go list -deps` compte le paquet parmi ses dépendances. Un test négatif qui tire sur une vraie violation l'apprend. |
| ⚫ | La mesure A donne deux paquets : la racine, et les tests de l'adaptateur qui le branchent sur la batterie. Le métier ne bouge pas. |
| ⚫ | Un type d'infrastructure entre dans le métier par un champ de structure plus souvent que par une signature. Le test d'architecture le voit quand même. |
