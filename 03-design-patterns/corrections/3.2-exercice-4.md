# Correction 3.2 — Exercice 4 : le SDK des paiements

> Rappel de l'énoncé : un SDK importé par douze équipes pendant trois ans,
> trois valeurs requises dont un secret, une dizaine de réglages facultatifs
> dont la moitié arrivent dans l'année, trois sources de réglages, et un
> secret qui ne doit apparaître dans aucun journal.

Ce qui suit s'appuie sur un SDK réduit — deux réglages, une opération —,
assez pour établir chaque décision par un test. Il tourne dans un module vert
sous `go vet ./...` et `go test -race -count=1 ./...`.

## 1. La forme du constructeur public

```go
// New returns a client, or the first rule its settings break.
func New(endpoint string, creds Credentials, opts ...Option) (*Client, error) {
    c := config{timeout: 10 * time.Second, http: http.DefaultClient}
    for _, o := range opts {
        o(&c)
    }
    switch {
    case !strings.HasPrefix(endpoint, "https://"):
        return nil, fmt.Errorf("%w: endpoint %q is not https", ErrSettings, endpoint)
    case creds.ClientID == "" || creds.Secret.reveal() == "":
        return nil, fmt.Errorf("%w: incomplete credentials", ErrSettings)
    case c.timeout <= 0:
        return nil, fmt.Errorf("%w: timeout %v", ErrSettings, c.timeout)
    case c.retries < 0:
        return nil, fmt.Errorf("%w: retries %d", ErrSettings, c.retries)
    case c.retries > 0 && c.keys == nil:
        return nil, fmt.Errorf("%w: %d retries need WithIdempotencyKeys, or a transfer may be paid twice", ErrSettings, c.retries)
    case c.http == nil:
        return nil, fmt.Errorf("%w: nil HTTP client", ErrSettings)
    }
    return &Client{endpoint: endpoint, creds: creds, c: c}, nil
}
```

Les options, pour deux raisons tirées de l'énoncé.

**« Attendus dans l'année »** : quatre réglages de plus, dans un SDK que douze
équipes appellent. La première mesure de la leçon dit ce que coûte chaque
forme quand un réglage arrive : les paramètres positionnels cassent chaque
appelant, les trois autres formes n'en cassent aucun.

**Trois ans** : parmi les trois formes qui ne cassent pas, une structure de
configuration exportée fige la sémantique du zéro de chaque champ **pour
toujours** — changer « zéro veut dire défaut » en « zéro veut dire zéro »
est un changement incompatible que le compilateur ne voit pas. Une option se
déprécie, se remplace, se documente une par une. Et le type `config` non
exporté ferme la liste : personne ne peut écrire une option que le SDK n'a
pas écrite, donc personne ne dépend des champs internes.

## 2. Le secret n'est pas une option

```go
// Credentials identify the calling team. They are required: a client
// without them can only fail, so they are a parameter, not an option.
type Credentials struct {
    ClientID string
    Secret   Secret
}
```

Une option est **facultative** : la compilation passe sans elle. Un client
sans identifiants ne peut qu'échouer, au premier appel, en production. En
paramètre, l'oubli ne compile pas ; en option, il compile, et le SDK doit
choisir entre refuser à la construction — une option qui n'en est pas une —
ou échouer à l'appel. La règle de la leçon tient sans exception : **ce qui
est requis est un paramètre**.

## 3. La règle qui lie les reprises et l'idempotence

Le défaut des reprises est **zéro** — un défaut sûr pour une API qui déplace
de l'argent — et la règle est contrôlée une fois, dans `New`, avec les
autres :

```
sdk: invalid settings: 3 retries need WithIdempotencyKeys, or a transfer may be paid twice
```

Refuser à la construction plutôt que de réessayer sans clé, ou de ne pas
réessayer en silence : l'équipe qui a écrit `WithRetries(3)` a une intention,
et le SDK lui dit, au démarrage, pourquoi il ne peut pas la tenir.

La règle a une deuxième moitié, que la campagne a vérifiée : la clé est
tirée **une fois par opération**, pas une fois par tentative. Une clé
nouvelle à chaque tentative ressemble à de l'idempotence et n'en est pas :

```go
// TestOneKeyPerTransfer: the attempts of one transfer carry the same key,
// so the API can pay it once; two transfers carry two keys.
func TestOneKeyPerTransfer(t *testing.T) {
    p := &partner{fails: 2}
    n := 0
    next := func() string { n++; return fmt.Sprintf("key-%d", n) }
    c := serve(t, p, WithRetries(3), WithIdempotencyKeys(next))
    for range 2 {
        if _, err := c.Transfer(context.Background(), "{}"); err != nil {
            t.Fatal(err)
        }
    }
    if got := strings.Join(p.keys, " "); got != "key-1 key-1 key-1 key-2" {
        t.Fatalf("keys: %s", got)
    }
}
```

## 4. Trois sources, un contrôle

Le fichier, l'environnement et les drapeaux sont lus par trois paquets
différents, en trois étapes : c'est le premier cas où la leçon dit qu'un
builder paie, et c'est ce que fait la solution, sous une forme plus simple —
**des couches** qu'on fusionne, puis qu'on traduit en options.

```go
// Layer is what one source of settings says: the file, the environment,
// the flags. A nil field is a setting this source does not mention, which
// is not the same as a setting it puts at zero.
type Layer struct {
    Timeout *time.Duration
    Retries *int
}
```

```go
// Merge applies the layers in order: a later layer overrides an earlier
// one only where it says something.
func Merge(layers ...Layer) Layer {
    var m Layer
    for _, l := range layers {
        if l.Timeout != nil {
            m.Timeout = l.Timeout
        }
        if l.Retries != nil {
            m.Retries = l.Retries
        }
    }
    return m
}
```

Les pointeurs, que la leçon déconseille dans une structure de configuration
**publique**, ont ici leur place exacte : une couche doit distinguer « cette
source ne dit rien » de « cette source dit zéro ». C'est ce qui fait passer
`--retries=0` par-dessus un `retries: 3` du fichier :

```go
// TestTheFlagsSayZero: the file says 3 retries, the environment says
// nothing about them, the flags say 0. Zero wins, because the layer of
// the flags says something.
func TestTheFlagsSayZero(t *testing.T) {
    file := Layer{Retries: ptr(3), Timeout: ptr(5 * time.Second)}
    env := Layer{Timeout: ptr(2 * time.Second)}
    flags := Layer{Retries: ptr(0)}
    m := Merge(file, env, flags)
    c, err := New("https://payments.internal", creds, m.Options()...)
    if err != nil {
        t.Fatal(err)
    }
    if s := c.Settings(); s.Retries != 0 || s.Timeout != 2*time.Second {
        t.Fatalf("%+v", s)
    }
    // Without the flags, the 3 retries of the file meet the rule of New.
    _, err = New("https://payments.internal", creds, Merge(file, env).Options()...)
    if !errors.Is(err, ErrSettings) {
        t.Fatalf("file and env: %v", err)
    }
}
```

Et le contrôle reste **unique** : les couches ne valident rien, `New` valide
le résultat de leur fusion. Le fichier seul, avec ses trois reprises et sans
générateur de clés, est refusé — par la même règle, au même endroit.

## 5. La valeur zéro

`var c sdk.Client` et `var p *sdk.Client` : `Transfer` rend `ErrNotBuilt`,
`Settings` rend des réglages vides. Les deux gardes sont testées, et la
campagne a vérifié que sans elles le test panique.

## 6. Le secret dans les journaux

Le type `Secret` masque toutes les façons de l'imprimer :

```go
// Secret is a credential. Every way of printing it prints a mask.
type Secret struct {
    value string
}
```

```go
// Format is used by every verb of fmt: %v, %+v, %#v, %s, %q, %x.
func (s Secret) Format(f fmt.State, verb rune) { fmt.Fprint(f, mask) }
```

```go
// LogValue is used by log/slog.
func (Secret) LogValue() slog.Value { return slog.StringValue(mask) }
```

**Et ça ne suffit pas.** Le test imprime les réglages, le secret, le client et
son pointeur de sept façons — cinq verbes de `fmt`, et `slog` en texte et en
JSON. Première version, sans rien d'autre que le type `Secret` :

| | `%v` `%+v` `%#v` `%s` `%q` | `slog` texte | `slog` JSON |
|---|---|---|---|
| `Settings` | masqué | masqué | masqué |
| `Secret` | masqué | masqué | masqué |
| `Client`, `*Client` | **le secret en clair** | **le secret en clair** | masqué |

Douze fuites sur quatorze impressions du client. Deux d'entre elles :

```
Client, slog text: level=INFO msg=start config="{endpoint:https://payments.internal creds:{ClientID:team-a Secret:{value:s3cr3t-value}} c:{timeout:10000000000 retries:0 keys:<nil> http:0x97b310}}"
*Client, %+v: &{endpoint:https://payments.internal creds:{ClientID:team-a Secret:{value:s3cr3t-value}} c:{timeout:10000000000 retries:0 keys:<nil> http:0x97b310}}
```

La cause : les champs de `Client` ne sont pas exportés, et **`fmt` imprime un
champ non exporté par réflexion, sans appeler ses méthodes** — le `Format` de
`Secret` compris. `Settings` est protégé parce que son champ `Credentials`
est exporté, donc `fmt` peut appeler les méthodes du secret. `slog` en JSON
est protégé par accident : `encoding/json` ignore les champs non exportés.

La réparation donne au client sa propre façon de s'imprimer — ses réglages,
où le secret est dans un champ exporté :

```go
// Format prints the client as its settings, for every verb: the fields of
// Client are unexported, and fmt prints unexported fields without calling
// their methods, Secret.Format included.
func (cl Client) Format(f fmt.State, verb rune) {
    fmt.Fprintf(f, "sdk.Client%+v", cl.settings())
}
```

```go
// LogValue logs the client as its settings.
func (cl Client) LogValue() slog.Value {
    s := cl.settings()
    return slog.GroupValue(
        slog.String("endpoint", s.Endpoint),
        slog.String("client_id", s.Credentials.ClientID),
        slog.Any("secret", s.Credentials.Secret),
        slog.Duration("timeout", s.Timeout),
        slog.Int("retries", s.Retries),
        slog.Bool("idempotent", s.Idempotent),
    )
}
```

```go
// TestTheSecretNeverPrints: the settings, the client and its pointer, in
// every way of printing them.
func TestTheSecretNeverPrints(t *testing.T) {
    c := newTestClient(t)
    for what, v := range map[string]any{"Settings": c.Settings(), "Client": *c, "*Client": c, "Secret": NewSecret(raw)} {
        for how, s := range prints(v) {
            if strings.Contains(s, raw) {
                t.Errorf("%s, %s: %s", what, how, strings.TrimSpace(s))
            }
        }
    }
}
```

Un dernier détail, trouvé par la campagne. Sans les deux `LogValue`, rien ne
fuit : `Format` suffit à masquer. Mais `slog` ne résout `LogValue` que sur
l'attribut lui-même, pas dans les champs d'une structure ; journalisés en
JSON, les réglages donnent ceci :

```
"Credentials":{"ClientID":"team-a","Secret":{}}
```

Un objet vide. L'opérateur qui lit ce journal pendant un incident conclut
que **le secret est vide** — et il cherche la panne au mauvais endroit. Le
masque doit se lire comme un masque ; le test qui l'exige :

```go
// TestTheLogSaysWhatItHides: not leaking is not enough. The effective
// configuration is logged to be read, and a masked secret must read as
// masked, not as an empty object an operator takes for a missing secret.
func TestTheLogSaysWhatItHides(t *testing.T) {
    var b bytes.Buffer
    slog.New(slog.NewJSONHandler(&b, nil)).Info("start", slog.Any("config", newTestClient(t)))
    for _, want := range []string{`"client_id":"team-a"`, `"secret":"[REDACTED]"`, `"timeout":10000000000`} {
        if !strings.Contains(b.String(), want) {
            t.Errorf("missing %s in %s", want, b.String())
        }
    }
}
```

Pour `fmt.Printf("%+v", cfg)` : c'est le `Format` du client qui protège, et
le test des sept impressions le vérifie à chaque livraison.

## 7. Ajouter, retirer

**v1.4, le proxy.** Une fonction nouvelle, `WithProxy(url string) Option`,
un champ dans `config`, une ligne de contrôle dans `New`. Changement
compatible : aucune équipe ne change rien, celles qui veulent un proxy
l'ajoutent. (Le SDK réduit passe par `WithHTTPClient`, qui couvre aussi le
proxy et le TLS ; un SDK réel peut offrir les deux.)

**v1.7, un réglage devenu inutile.** On ne **retire** pas l'option en v1 :
retirer une fonction exportée casse chaque équipe qui l'appelle. On la garde,
sans effet, avec un commentaire `Deprecated:` qui dit pourquoi et par quoi la
remplacer, et on la retire en v2. La correction 3.2/3 a mesuré ce que vaut
ce commentaire : **une documentation, pas une alarme** — ni `staticcheck`
ni `gopls` ne l'ont signalé. L'annonce passe par la note de version.

Une option sans effet a un piège : si elle **portait une règle** — une
reprise exigeant une clé, par exemple —, la rendre muette change le
comportement de ceux qui l'appellent encore. Une option dépréciée garde son
contrôle jusqu'à son retrait.

## 8. Le `DefaultClient` global

Non, pour trois raisons que la leçon a mesurées. Un client global a
besoin d'identifiants : il les lit dans l'environnement à l'initialisation du
paquet, donc **une dépendance cachée** que la signature de l'appelant ne dit
plus. Ses réglages sont partagés par toutes les équipes du même binaire :
celle qui change son délai change celui des autres — les défauts partagés de
la leçon, section 9. Et ses tests ne peuvent pas tourner en parallèle.
`http.DefaultClient` peut exister parce qu'un client HTTP n'a pas de
secret ; celui-ci en a un. La leçon 3.6 reprend la question avec le
singleton.

## 9. La campagne

Quinze modifications sur le SDK réduit. Première passe :

```
reprises sans cle acceptees                    tuee
une cle par tentative                          tuee
une tentative de moins                         SURVIT
sans authentification                          tuee
cle jamais envoyee                             tuee
http accepte                                   tuee
Transfer : plus de garde                       tuee
Settings : plus de garde                       tuee
Client sans Format                             tuee
Client sans LogValue                           SURVIT
Secret sans Format                             tuee
Secret sans LogValue                           SURVIT
couche : retries toujours ecrase               tuee
couche : la premiere gagne                     tuee
secret vide accepte                            tuee
12/15 tuees
```

**« Une tentative de moins ».** Aucun test ne consommait toutes les reprises
avant de réussir : avec deux échecs et trois reprises, la dernière n'est
jamais jouée.

```go
// TestTheLastRetryCounts: three retries are four attempts.
func TestTheLastRetryCounts(t *testing.T) {
    p := &partner{fails: 3}
    c := serve(t, p, WithRetries(3), WithIdempotencyKeys(func() string { return "k" }))
    attempts, err := c.Transfer(context.Background(), "{}")
    if attempts != 4 || err != nil {
        t.Fatalf("%d attempts, %v", attempts, err)
    }
}
```

**« Client sans LogValue » et « Secret sans LogValue ».** Aucune fuite — c'est
la section 6 : `Format` masquait déjà. Les deux survivants disaient que rien
ne vérifiait que le journal reste **lisible**, et c'était une exigence de
l'énoncé. `TestTheLogSaysWhatItHides` les tue tous les deux.

Deuxième passe :

```
15/15 tuees
```

## Ce qu'il faut retenir

| | |
|---|---|
| ⚫ | Pour une API publique qui vivra des années : requis en paramètres, facultatifs en options, `config` non exporté. |
| ⚫ | Le secret est requis : en option, son oubli compile. |
| ⚫ | Une règle qui protège l'argent se contrôle à la construction, avec un défaut sûr ; et une clé d'idempotence se tire par opération, pas par tentative. |
| ⚫ | Trois sources de réglages : des couches à pointeurs, fusionnées, traduites en options, contrôlées une fois. Les pointeurs y ont leur place : une couche doit pouvoir dire « rien ». |
| ⚫ | Un type `Secret` masqué ne protège pas un champ non exporté : `fmt` l'imprime sans appeler ses méthodes. Mesuré : 12 fuites sur 14 impressions du client. |
| ⚫ | `slog` ne résout `LogValue` qu'au premier niveau : un secret imbriqué s'imprime `{}` en JSON. Masqué, mais trompeur. |
| ⚫ | On ne retire pas une option dans une version mineure ; une option dépréciée garde ses contrôles. |
