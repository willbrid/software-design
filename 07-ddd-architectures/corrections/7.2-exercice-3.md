# Correction 7.2 — Exercice 3 : les SMS sans l'opérateur

> Rappel de l'énoncé : réécrire les SMS pour qu'ils ne dépendent ni de
> l'opérateur ni du membre partagé ; un test d'architecture le vérifie.

La solution est dans `ex3` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Les SMS parlent la langue des paiements** (`payments.Outcome`), pas
  celle de l'opérateur.
- **Un message par résultat et par langue**, dans une table.
- **La règle d'architecture est un test** : elle échoue le jour où
  quelqu'un réimporte l'opérateur.

## 1. La solution

```go
// Message is the SMS after a payment whose outcome is o: in the member's
// language, one per outcome (confirmed, failed, reversed, waiting). An
// unknown language falls back to French.
func Message(c Contact, o payments.Outcome) string {
    byOutcome, found := messages[c.Language]
    if !found {
        byOutcome = messages["fr"]
    }
    return fmt.Sprintf(byOutcome[o], c.Name)
}
```

Le message d'annulation n'existait pas : l'ancien code ne connaissait que
« reçu » et « non reçu ». Le membre dont le paiement est annulé reçoit
désormais un message qui lui dit **que sa cotisation n'est pas payée**,
au lieu d'un « paiement non reçu » qui contredit le « paiement reçu » de
la veille.

## 2. Une règle d'architecture en test

Dans un document, la règle « les SMS ne dépendent pas de l'opérateur » est
lue une fois, puis oubliée. En test, elle est vérifiée à chaque
`go test`, et le jour où un développeur pressé importe `operator` pour
afficher un code d'erreur, la CI lui dit pourquoi c'est refusé, avec le
nom du fichier.

Le test lit seulement les imports (`parser.ImportsOnly`) : il est rapide,
et ne dépend d'aucun outil extérieur. La leçon 7.5 généralise l'idée à
tout le module, avec `go list`.

## Ce qu'il faut retenir

- Un contexte parle les mots de ses voisins proches, pas ceux de
  l'extérieur.
- Un nouveau résultat demande un nouveau message, pas un repli muet.
- Une règle d'architecture qui compte s'écrit en test.
