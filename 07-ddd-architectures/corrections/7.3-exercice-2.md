# Correction 7.3 — Exercice 2 : payer par USSD

> Rappel de l'énoncé : un adaptateur qui pilote l'application depuis le
> texte USSD.

La solution est dans `ex2` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **L'adaptateur lit le texte et traduit la réponse** ; il ne décide rien.
- **Aucune règle de la cotisation n'est réécrite** : le montant, le
  deuxième paiement, le tour clos sont refusés par l'agrégat, à travers le
  service.
- **Le numéro vient de l'opérateur**, qui l'a authentifié, pas du texte
  tapé.

## 1. La solution

```go
func (u USSD) Handle(ctx context.Context, phone, text string) string {
    number, amount, ok := parse(text)
    if !ok {
        return "Saisie invalide. Tapez *123*<tour>*<montant>#"
    }
    err := u.App.Contribute(ctx, u.Round(phone, number), phone, amount)
    switch {
    case err == nil:
        return "Cotisation reçue. Merci."
    case errors.Is(err, round.ErrAlreadyPaid):
        return "Vous avez déjà payé ce tour."
    case errors.Is(err, round.ErrBadAmount):
        return "Montant incorrect."
    case errors.Is(err, round.ErrClosed):
        return "Ce tour est clos."
    }
    return "Service indisponible, réessayez plus tard."
}
```

```go
// parse reads "*123*<round>*<amount>#": ASCII digits only.
func parse(text string) (number int, amount int64, ok bool) {
    body, found := strings.CutPrefix(text, "*123*")
    if !found {
        return 0, 0, false
    }
    body, found = strings.CutSuffix(body, "#")
    parts := strings.Split(body, "*")
    if !found || len(parts) != 2 {
        return 0, 0, false
    }
    n, err1 := strconv.Atoi(parts[0])
    a, err2 := strconv.ParseInt(parts[1], 10, 64)
    if err1 != nil || err2 != nil || n < 1 || a < 1 {
        return 0, 0, false
    }
    return n, a, true
}
```

## 2. La règle réécrite

**Aucune.** L'adaptateur ne vérifie que la **forme** du texte : le préfixe,
les deux nombres, le `#`. Ce qui fait qu'une cotisation est acceptée (le
montant égal à la part, un seul paiement, le tour ouvert) reste dans
`round.Round`, et l'adaptateur traduit l'erreur en écran. C'est la
différence avec le canal USSD de la leçon 7.1, qui avait réécrit sa
propre vérification et en avait oublié la moitié.

Le tour inconnu (`*123*9*...`) répond « Service indisponible » : c'est
`app.ErrNoRound`, que l'adaptateur ne traduit pas. Un écran « ce tour
n'existe pas » serait plus juste ; il suffit d'un cas de plus dans le
`switch`, sans rien toucher au service.

## Ce qu'il faut retenir

- Un adaptateur qui pilote vérifie la forme, et traduit les erreurs.
- Un nouveau canal ne réécrit aucune règle.
- L'identité vient de ce qui l'authentifie, pas de ce que la personne
  tape.
