# Correction 7.1 — Exercice 2 : l'agrégat d'un prêt

> Rappel de l'énoncé : écrire les règles d'un prêt dans son agrégat.

La solution est dans `ex2` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Un état** (`requested`, `granted`, `refused`, `repaid`) et des
  méthodes qui ne sont permises que dans certains états : c'est la machine
  à états de la leçon 3.5, dans un agrégat.
- **Une seule décision** : `Grant` et `Refuse` passent par `decide`, qui
  refuse tout ce qui n'est pas `requested`.
- **Le passage à `repaid` est automatique**, quand plus rien ne reste.

## 1. La solution

```go
// Request asks for a loan of amount, within limit.
func Request(amount, limit int64) (*Loan, error) {
    switch {
    case amount <= 0:
        return nil, ErrNotPositive
    case amount > limit:
        return nil, ErrTooHigh
    }
    return &Loan{amount: amount, state: "requested"}, nil
}
```

```go
// Repay records a repayment.
func (l *Loan) Repay(amount int64) error {
    switch {
    case l.state == "repaid":
        return ErrRepaid
    case l.state != "granted":
        return ErrNotGranted
    case amount <= 0:
        return ErrNotPositive
    case amount > l.Left():
        return ErrTooMuch
    }
    l.repaid += amount
    if l.Left() == 0 {
        l.state = "repaid"
    }
    return nil
}
```

```go
// Left is what is left to repay: the amount plus 10 %, less what was
// repaid; 0 for a loan that was not granted.
func (l *Loan) Left() int64 {
    if l.state != "granted" && l.state != "repaid" {
        return 0
    }
    return l.amount + l.amount/10 - l.repaid
}
```

## 2. Pourquoi `Left` rend 0 avant l'accord

Un prêt demandé n'est pas une dette : tant que la trésorière n'a pas
accordé, le membre ne doit rien. Si `Left` rendait 110 000 FCFA, l'écran
du relevé (leçon 6.5) l'afficherait comme dû, et un refus le ferait
disparaître : le membre verrait une dette apparaître et disparaître. La
règle « on ne doit que ce qui a été accordé » est **dans l'agrégat**, et
chaque écran la reçoit sans la connaître.

## Ce qu'il faut retenir

- Un agrégat avec un état : chaque méthode dit dans quels états elle est
  permise.
- Ce qui se déduit (`Left`, le passage à `repaid`) se calcule dans
  l'agrégat, pas chez l'appelant.
- Une valeur affichée suit une règle : elle vit dans l'agrégat aussi.
