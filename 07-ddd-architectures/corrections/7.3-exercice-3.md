# Correction 7.3 — Exercice 3 : les rappels de la veille

> Rappel de l'énoncé : un service qui lit `time.Now()` et appelle la
> passerelle SMS directement ; le faire passer par ses ports.

La solution est dans `ex3` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **L'heure vient du port `Now`**, et les messages du port `Notify` : le
  service ne connaît plus ni l'horloge du serveur ni l'adresse de la
  passerelle.
- **Le test choisit l'heure** : 17 h 59, 18 h 00, minuit, à la minute
  près.
- **Le `main`** branche `time.Now` et `sms.Gateway`.

## 1. La solution

```go
// Reminders sends the reminders, through two ports: the clock, and the
// messages.
type Reminders struct {
    Now    func() time.Time
    Notify app.Notifier
}
```

```go
// Send reminds each member who has not paid, if now is the day before the
// round, from 18:00. It returns how many reminders went out.
func (r Reminders) Send(ctx context.Context, round Round) int {
    now := r.Now()
    eve := round.Date.AddDate(0, 0, -1).Add(18 * time.Hour)
    if now.Before(eve) || !now.Before(round.Date) {
        return 0
    }
    sent := 0
    for _, phone := range round.Unpaid {
        if r.Notify.Notify(ctx, phone, fmt.Sprintf("Rappel : demain, cotisation de %d FCFA", round.ShareFCFA)) == nil {
            sent++
        }
    }
    return sent
}
```

## 2. Comment on le testait avant

**On ne le testait pas**, ou mal :

- pour vérifier la fenêtre de 18 h, il fallait lancer le test la veille
  d'un tour, après 18 h, ou changer l'horloge de la machine ;
- chaque test envoyait de vrais SMS à la passerelle, ou échouait quand le
  réseau manquait (c'est ce qui arrive dans le module d'exercices : la
  passerelle n'existe pas, aucun rappel ne part) ;
- le bord de minuit, où la veille devient le jour même, n'était vérifié
  que le soir où un membre recevait un rappel en retard.

Avec les ports, les cinq heures du test se vérifient en une
milliseconde, et sans réseau.

## Ce qu'il faut retenir

- L'heure est une dépendance extérieure : un port.
- Un service testable à toute heure se teste aux bords.
- Le choix des vrais adaptateurs se fait dans `main`, une fois.
