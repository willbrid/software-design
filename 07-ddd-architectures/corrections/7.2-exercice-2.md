# Correction 7.2 — Exercice 2 : un second opérateur

> Rappel de l'énoncé : traduire les rappels de kash dans les événements
> du contexte des paiements.

La solution est dans `ex2` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Une seconde couche anti-corruption, à côté de la première** : chacune
  connaît un opérateur, et produit les mêmes événements.
- **Les unités se convertissent à la frontière** : des centimes de kash
  aux FCFA entiers des paiements, avec un refus pour une fraction de
  franc.
- **Le contexte des paiements ne change pas.**

## 1. La solution

```go
func Translate(c KashCallback) (payments.Event, error) {
    outcome, known := states[c.State]
    if !known {
        return payments.Event{}, fmt.Errorf("%w %q for %s", ErrUnknownState, c.State, c.Reference)
    }
    if c.Currency != "XAF" {
        return payments.Event{}, fmt.Errorf("currency %q for %s", c.Currency, c.Reference)
    }
    if c.AmountMinor <= 0 || c.AmountMinor%100 != 0 {
        return payments.Event{}, fmt.Errorf("amount %d centimes for %s", c.AmountMinor, c.Reference)
    }
    digits, _ := strings.CutPrefix(c.Phone, "+237")
    if len(digits) != 9 || strings.Trim(digits, "0123456789") != "" {
        return payments.Event{}, fmt.Errorf("phone %q for %s", c.Phone, c.Reference)
    }
    return payments.Event{Contribution: c.Reference, Phone: "+237" + digits, AmountFCFA: c.AmountMinor / 100, Outcome: outcome}, nil
}
```

écrite autrement.

## 2. Ce qui change dans les paiements

**Rien.** `payments.Event` et `Ledger` ne savent pas qu'il existe deux
opérateurs : ils reçoivent des cotisations confirmées, échouées, annulées
ou en attente, en FCFA, avec un numéro au format `+237`. Le gestionnaire
HTTP qui reçoit les rappels de kash appelle `ex2.Translate`, celui de
l'opérateur historique appelle `acl.Translate`, et les deux donnent leur
événement au même registre.

C'est le test de la frontière : quand un deuxième système extérieur
arrive, seule une nouvelle couche s'écrit. Si le contexte devait changer
(un champ `Operator` partout, un `switch` sur le nom de l'opérateur dans
le registre), la frontière était au mauvais endroit.

## Ce qu'il faut retenir

- Une couche anti-corruption par système extérieur.
- Les unités et les formats se convertissent à la frontière, une fois.
- Un nouveau système extérieur ne change pas le contexte.
