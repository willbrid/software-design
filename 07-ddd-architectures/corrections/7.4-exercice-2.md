# Correction 7.4 — Exercice 2 : vérifier toutes les correspondances d'un coup

> Rappel de l'énoncé : un test générique qui remplit chaque champ, passe
> la valeur dans une correspondance, et dit les champs perdus.

La solution est dans `ex2` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **La réflexion remplit chaque champ exporté** d'une valeur à lui.
- **On compare champ par champ** ce qui revient de la correspondance.
- **Un test d'une ligne par correspondance** : `Survives(toRowThenBack)`
  ne dit rien tant que tout revient.

## 1. La solution

```go
func Survives[T any](f func(T) T) []string {
    var in T
    v := reflect.ValueOf(&in).Elem()
    for i := range v.NumField() {
        field := v.Field(i)
        if !v.Type().Field(i).IsExported() {
            continue
        }
        switch field.Kind() {
        case reflect.String:
            field.SetString(fmt.Sprintf("value of %s", v.Type().Field(i).Name))
        case reflect.Int, reflect.Int8, reflect.Int16, reflect.Int32, reflect.Int64:
            field.SetInt(int64(1000 + i)) // a different value for each field
        case reflect.Bool:
            field.SetBool(true) // false is the zero value: true must come back
        }
    }
    out := reflect.ValueOf(f(in))
    var lost []string
    for i := range v.NumField() {
        if v.Type().Field(i).IsExported() && !reflect.DeepEqual(v.Field(i).Interface(), out.Field(i).Interface()) {
            lost = append(lost, v.Type().Field(i).Name)
        }
    }
    return lost
}
```

## 2. Pourquoi des valeurs différentes

Avec la même valeur partout (`"x"` dans chaque texte), une correspondance
qui **échange** deux champs (`Name: m.Phone, Phone: m.Name`) rendrait
`"x"` dans les deux : le test ne verrait rien. Avec une valeur propre à
chaque champ (`"value of Name"`), l'échange se voit. De même, un booléen
reçoit `true` : `false` est la valeur zéro, celle qu'une correspondance
qui oublie le champ rend sans le savoir.

Le test a ses limites : il ne remplit que les textes, les entiers et les
booléens. Une structure imbriquée, une liste ou une date demanderaient
d'étendre le remplissage, ou un test écrit à la main pour ces champs.

## Ce qu'il faut retenir

- Un test générique vérifie chaque champ, y compris ceux ajoutés demain.
- Des valeurs différentes, et jamais la valeur zéro.
- Il ne remplace pas le test du comportement : il vérifie les copies.
