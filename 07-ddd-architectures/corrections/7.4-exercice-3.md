# Correction 7.4 — Exercice 3 : le profil sans les cercles

> Rappel de l'énoncé : réécrire le profil en un seul paquet, avec le même
> comportement que la version en cercles.

La solution est dans `ex3` du module de correction, verte sous
`go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **Un type, un stockage, un gestionnaire** : 66 lignes au lieu de 250.
- **Le comportement est le même**, requête par requête, y compris les
  erreurs (`400`, `404`, `422`).
- **La règle du nom reste**, et la règle des dépendances aussi.

## 1. La solution

```go
// Handler serves PUT /members/{id}.
func Handler(s *Store) http.Handler {
    mux := http.NewServeMux()
    mux.HandleFunc("PUT /members/{id}", func(w http.ResponseWriter, r *http.Request) {
        var p Profile
        if err := json.NewDecoder(r.Body).Decode(&p); err != nil {
            http.Error(w, "malformed", http.StatusBadRequest)
            return
        }
        p.ID = r.PathValue("id")
        if _, found := s.Get(p.ID); !found {
            http.NotFound(w, r)
            return
        }
        if p.Name == "" {
            http.Error(w, "a name is required", http.StatusUnprocessableEntity)
            return
        }
        s.Put(p)
        w.Header().Set("Content-Type", "application/json")
        _ = json.NewEncoder(w).Encode(p)
    })
    return mux
}
```

## 2. Ce qui est supprimé, ce qui est gardé

**Supprimés** : l'entité et sa méthode `Rename`, la requête et la réponse
du cas d'utilisation, les ports d'entrée et de sortie, le présentateur
et sa vue, la passerelle et ses deux correspondances, la ligne de la
table. Six structures pour une seule donnée, et sept copies.

**Gardés** :

- **la règle** « un nom est requis », devenue une condition de deux
  lignes dans le gestionnaire ;
- **la règle des dépendances** : le paquet n'importe que la bibliothèque
  standard. Le jour où le profil passera sur PostgreSQL, `Store` devient
  une interface avec un adaptateur, comme à la leçon 7.3, et le
  gestionnaire ne change pas ;
- **le test d'équivalence**, qui a prouvé le refactoring : il reste utile
  tant que les deux versions coexistent pendant la migration.

## Ce qu'il faut retenir

- Retirer des couches est un refactoring : un test d'équivalence le
  prouve.
- La règle survit aux cercles ; elle se déplace.
- La règle des dépendances ne demande pas de cercles.
