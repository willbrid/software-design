# Correction 7.5 — Exercice 2 : la question au lieu de la jointure

> Rappel de l'énoncé : ajouter `ConfirmedAmong` à la face publique des
> paiements, pour que les tontines comptent sans jointure.

La solution est dans `ex2` et dans `modules/payments` du module de
correction, verte sous `go vet ./...` et `go test -race -count=1 ./...`.

## En bref

- **La face publique gagne une question**, et l'intérieur la requête qui
  y répond, dans son schéma.
- **Une requête pour tout le tour**, avec `= ANY($1)` sur la liste des
  cotisations.
- **Chaque cotisation a une réponse**, `false` quand elle est absente du
  registre.

## 1. La solution

```go
// ConfirmedAmong returns, for each of contributions, whether it is paid:
// one query, in the schema of the payments, for a whole round.
func (a *API) ConfirmedAmong(ctx context.Context, contributions []string) (map[string]bool, error) {
    return a.ledger.ConfirmedAmong(ctx, contributions)
}
```

```go
// ConfirmedAmong reads, in one query, which of contributions are
// confirmed; each of them has an answer, false when it is not in the
// ledger.
func (l Ledger) ConfirmedAmong(ctx context.Context, contributions []string) (map[string]bool, error) {
    out := make(map[string]bool, len(contributions))
    for _, c := range contributions {
        out[c] = false
    }
    rows, err := l.Pool.Query(ctx, `SELECT contribution FROM ledger
        WHERE contribution = ANY($1) AND outcome = 'confirmed'`, contributions)
    if err != nil {
        return nil, err
    }
    confirmed, err := pgx.CollectRows(rows, pgx.RowTo[string])
    for _, c := range confirmed {
        out[c] = true
    }
    return out, err
}
```

## 2. Pourquoi pas une boucle

Une boucle sur `Confirmed` ferait **une requête par cotisation** : 25 pour
un tour, 1 000 pour les 40 tontines d'un dimanche. C'est le N+1 de la
leçon 5.5, à travers une frontière de module. La jointure de la première
version était rapide pour cette raison, et c'est ce qui la rendait
tentante.

`ConfirmedAmong` garde la vitesse (une requête) et la frontière (dans le
schéma des paiements, par leur code). Quand une question d'un module à
un autre se pose « pour beaucoup », la face publique offre la version
« pour beaucoup ».

## Ce qu'il faut retenir

- Une question fréquente « pour beaucoup » mérite sa fonction dans la face
  publique.
- Une frontière de module ne justifie pas un N+1.
- Chaque élément demandé a une réponse, même « absent ».
