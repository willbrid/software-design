Cinq exercices, du plus simple au plus ouvert. Traite-les **dans l'ordre** et
écris tes réponses dans `mes-reponses/` avant d'ouvrir les corrections.

Les exercices s'appuient sur la version `v2` de la
[leçon 7.4](../cours/7.4-le-cout-des-couches.md) (`v2/layered`,
`v2/direct`), recopiée telle quelle dans le module des exercices. Ils
n'ont besoin que de la bibliothèque standard. Tout le code ci-dessous
compile et passe `go vet` ; les membres et l'incident sont **fictifs**.

## Exercice 5 — Incident : les reçus qui ne partaient pas

*Niveau 7. Un incident à mesurer, puis à corriger.*

En décembre 2026, l'équipe ajoute l'envoi hebdomadaire des reçus par
e-mail, à partir du profil en cercles. Le cas d'utilisation lit le membre
par la passerelle :

```go
// SendReceipts is the use case of the receipts: each member who gave an
// e-mail receives the receipt of the week. It returns how many were sent,
// and how many members were skipped for having no e-mail.
func SendReceipts(members interface {
    Find(id string) (entity.Member, error)
}, ids []string, week string, mail Mailer) (sent, skipped int) {
    for _, id := range ids {
        m, err := members.Find(id)
        if err != nil {
            continue
        }
        if m.Email == "" {
            skipped++
            continue
        }
        if mail.Send(m.Email, fmt.Sprintf("Reçu de vos cotisations, semaine %s", week)) == nil {
            sent++
        }
    }
    return sent, skipped
}
```

La passerelle de production :

```go
// Find reads a member.
func (g Members) Find(id string) (entity.Member, error) {
    r, err := g.Table.Get(id)
    if err != nil {
        return entity.Member{}, err
    }
    return entity.Member{ID: r.ID, Name: r.Name, Phone: r.Phone, Town: r.Town}, nil
}
```

Fin décembre, des membres demandent pourquoi ils n'ont jamais reçu de
reçu, alors qu'ils ont donné leur e-mail.

```go
// December replays the first three weeks of the receipts: 600 members;
// each week, more of them give their e-mail through the profile screen
// (the layered PUT /members/{id}); every Sunday, the receipts run through
// the gateway made by newGateway. It returns the table and the weeks.
func December(newGateway func(*db.Table) Finder) (*db.Table, []Week) {
    rnd := rand.New(rand.NewPCG(12, 2026))
    table := db.NewTable()
    var ids []string
    for i := range 600 {
        id := fmt.Sprintf("m%03d", i)
        ids = append(ids, id)
        table.Put(db.MemberRow{ID: id, Name: "Membre " + id, Phone: fmt.Sprintf("+2376770%05d", i), Town: "Douala"})
    }
    screen := wiring.Handler(table)
    var weeks []Week
    for _, name := range []string{"2026-W49", "2026-W50", "2026-W51"} {
        for _, id := range ids {
            if rnd.Float64() < 0.15 { // gives an e-mail this week, on the profile screen
                r, _ := table.Get(id)
                body := fmt.Sprintf(`{"name":%q,"phone":%q,"town":%q,"email":"%s@example.org"}`, r.Name, r.Phone, r.Town, id)
                screen.ServeHTTP(httptest.NewRecorder(), httptest.NewRequest("PUT", "/members/"+id, strings.NewReader(body)))
            }
        }
        out := &Outbox{}
        sent, skipped := SendReceipts(newGateway(table), ids, name, out)
        weeks = append(weeks, Week{name, sent, skipped})
    }
    return table, weeks
}
```
