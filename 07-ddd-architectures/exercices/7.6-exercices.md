# Exercices 7.6 — Extraire un module en service

Cinq exercices, du plus simple au plus ouvert. Traite-les **dans l'ordre** et
écris tes réponses dans `mes-reponses/` avant d'ouvrir les corrections.

Les exercices s'appuient sur les paquets de la
[leçon 7.6](../cours/7.6-extraire-un-service.md) (`payments`, `paysvc`,
`payclient`, `strangler`, `loans`, `slow`), recopiés tels quels dans le
module des exercices. Ils n'ont besoin que de la bibliothèque standard.
Tout le code ci-dessous compile et passe `go vet` ; les tontines et
l'incident sont **fictifs**.

## Exercice 1 — Compréhension : extraire ou pas ?

*Niveau 1. Aucune ligne de code à écrire.*

### 1.a — Cinq raisons

Pour chacune, dis si elle justifie d'extraire le module des paiements en
service, et pourquoi.

1. « Les microservices, c'est l'architecture moderne. »
2. « L'opérateur impose un audit de sécurité sur tout code qui touche
   l'argent, à chaque livraison. »
3. « Le module des paiements est lent. »
4. « L'équipe des paiements livre trois fois par jour, le reste de
   l'application une fois par semaine. »
5. « Les tests du monolithe prennent douze minutes. »

### 1.b — Trois pourquoi

1. Pourquoi la boucle sur `Confirmed` coûte-t-elle 46 ms avec le service,
   et rien avec le module ?
2. Pourquoi `MayBorrowNaive` refuse-t-il 58 membres à jour ?
3. Pourquoi l'ombre répond-elle avec l'ancien module, et pas avec le
   service ?

### 1.c — Quand arrêter l'ombre ?

L'ombre ne montre plus aucune différence depuis une semaine. Que faut-il
encore voir passer avant de passer à 10 % ?

## Exercice 5 — Incident : la bascule du dimanche

*Niveau 7. Un incident à mesurer, puis à rejouer comme il aurait dû
être fait.*

Le dimanche 22 novembre 2026, l'équipe des paiements bascule la question
des tontines vers le nouveau service, à 100 %, sans ombre, avec la
première migration de la leçon. Les cagnottes du jour sont versées.

```go
// Sunday pays out the 40 pots through a router made by newRouter, on top of
// the module and of a service migrated by migrate.
func Sunday(migrate func(map[string]string) *paysvc.Service, newRouter func(old, nw strangler.Payments) *strangler.Router) ([]Pot, strangler.Report) {
    ctx := context.Background()
    m, rounds, shares := Setup()
    srv := httptest.NewServer(migrate(m.Outcomes()).Handler())
    defer srv.Close()
    r := newRouter(m, payclient.Client{HTTP: srv.Client(), URL: srv.URL, Timeout: time.Second})
    var pots []Pot
    for t := 1; t <= 40; t++ {
        said, err := r.ConfirmedAmong(ctx, rounds[t])
        if err != nil {
            panic(err)
        }
        truth, _ := m.ConfirmedAmong(ctx, rounds[t])
        p := Pot{Tontine: t, ShareFCFA: shares[t]}
        for _, id := range rounds[t] {
            if said[id] {
                p.PaidOutFCFA += shares[t]
            }
            if truth[id] {
                p.InLedgerFCFA += shares[t]
            }
        }
        pots = append(pots, p)
    }
    return pots, r.Report()
}
```
