# Exercices 7.5 — Le monolithe modulaire

Cinq exercices, du plus simple au plus ouvert. Traite-les **dans l'ordre** et
écris tes réponses dans `mes-reponses/` avant d'ouvrir les corrections.

Les exercices s'appuient sur les paquets de la
[leçon 7.5](../cours/7.5-le-monolithe-modulaire.md) (`modules`, `ball`,
`internal/pg`), recopiés dans le module des exercices ; la face publique
des paiements y gagne `Schema` et le squelette de `ConfirmedAmong`. Les
exercices 2 et 5 demandent le même PostgreSQL 17 que la leçon. Tout le
code ci-dessous compile et passe `go vet` ; les tontines et l'incident
sont **fictifs**.

## Exercice 1 — Compréhension : qui arrête quoi ?

*Niveau 1. Aucune ligne de code à écrire.*

### 1.a — Six raccourcis

Pour chaque raccourci, dis ce qui l'arrête : le compilateur, le test
d'architecture, PostgreSQL, ou rien.

1. Les tontines importent `modules/payments/internal/ledger`.
2. Les paiements importent `modules/tontines` pour appeler `UpToDate`.
3. Les tontines font `SELECT ... FROM payments.ledger` avec leur rôle.
4. Les prêts importent `modules/tontines`, ce que la table `allowed` ne
   prévoit pas.
5. Les tontines copient le code de `ledger.Outcome` dans leur propre
   paquet, avec la même requête.
6. `main` importe les trois modules.

### 1.b — Trois pourquoi

1. Pourquoi les tontines déclarent-elles une interface `Payments` au lieu
   d'importer `modules/payments` ?
2. Pourquoi `cmd/impact` compte-t-il trois paquets dans les deux versions,
   alors que la version modulaire est meilleure ?
3. Pourquoi le `search_path` du pool d'un module vaut-il son schéma ?

### 1.c — Un module ou deux ?

Les tontines et les paiements doivent clore un tour et enregistrer le
versement « ensemble ». Une collègue propose de fusionner les deux
modules. Qu'en penses-tu ?

```go
// Sunday creates a fresh database with the schemas of the two modules,
// fills the round 12 of 40 tontines, runs the migration of Saturday, and
// returns the rounds of Sunday.
func Sunday(ctx context.Context) ([]Round, error) {
    db := fmt.Sprintf("m75_sunday_%06x", rand.Uint32()&0xffffff)
    admin, err := pgx.Connect(ctx, pg.URL())
    if err != nil {
        return nil, err
    }
    defer admin.Close(ctx)
    if _, err := admin.Exec(ctx, "CREATE DATABASE "+db); err != nil {
        return nil, err
    }
    defer admin.Exec(context.Background(), "DROP DATABASE "+db+" WITH (FORCE)")
    u, _ := url.Parse(pg.URL())
    u.Path = "/" + db
    conn, err := pgx.Connect(ctx, u.String())
    if err != nil {
        return nil, err
    }
    defer conn.Close(ctx)
    for _, ddl := range []string{
        `CREATE SCHEMA tontines`, `CREATE SCHEMA payments`,
        `CREATE TABLE tontines.contribution (id text PRIMARY KEY, tontine int NOT NULL, round int NOT NULL, member text NOT NULL)`,
        `CREATE TABLE payments.ledger (contribution text PRIMARY KEY, amount_fcfa bigint NOT NULL, outcome text NOT NULL)`,
    } {
        if _, err := conn.Exec(ctx, ddl); err != nil {
            return nil, err
        }
    }
    rnd := rand.New(rand.NewPCG(15, 11))
    shares := map[int]int64{}
    for t := 1; t <= 40; t++ {
        shares[t] = int64(5_000 * (1 + rnd.IntN(6)))
        for m := range 25 {
            id := fmt.Sprintf("t%02d-r12-m%02d", t, m)
            outcome := "confirmed"
            switch k := rnd.Float64(); {
            case k < 0.03:
                outcome = "reversed"
            case k < 0.06:
                outcome = "failed"
            }
            if _, err := conn.Exec(ctx, `INSERT INTO tontines.contribution VALUES ($1, $2, 12, $3)`, id, t, fmt.Sprint("m", m)); err != nil {
                return nil, err
            }
            if _, err := conn.Exec(ctx, `INSERT INTO payments.ledger VALUES ($1, $2, $3)`, id, shares[t], outcome); err != nil {
                return nil, err
            }
        }
    }
    for _, step := range strings.Split(strings.TrimSpace(Migration), ";") {
        if strings.TrimSpace(step) == "" {
            continue
        }
        if _, err := conn.Exec(ctx, step); err != nil {
            return nil, err
        }
    }
    var rounds []Round
    for t := 1; t <= 40; t++ {
        r := Round{Tontine: t, Number: 12, ShareFCFA: shares[t]}
        if err := conn.QueryRow(ctx, JoinOfTheTontines, t, 12).Scan(&r.Counted); err != nil {
            return nil, err
        }
        if err := conn.QueryRow(ctx, AskThePayments, t, 12).Scan(&r.Paid); err != nil {
            return nil, err
        }
        rounds = append(rounds, r)
    }
    return rounds, nil
}
```
